このサイトの学び方

1. 図でイメージを掴む

スタースキーマもフィルターコンテキストも、文章より図のほうが速く腹落ちします。全レッスンに図解を入れています。

2. 手を動かす

サンプルデータ付きのハンズオンラボで、実際にPower BI Desktopを操作します。詰まったときの答えも用意しています。

3. クイズで定着させる

レッスンごとの確認クイズと、本番形式の模擬試験。間違えた問題は自動で復習リストになります。

ゴールは PL-300 合格

PL-300 は「データの準備」「データのモデル化」「視覚化と分析」「資産の管理とセキュリティ」の4領域から出題されます。 本サイトのLv.1〜Lv.5はこの4領域に対応づけて構成しています。
