## 精度をどう測るか

```figure
{ "type":"cards", "cols":2, "title":"4つの誤差指標", "caption":"目的に合ったものを選ぶ", "items":[
    {"icon":"📏","title":"MAE 平均絶対誤差","text":"平均(|実績−予測|)。単位そのままで外れ値に穏やか。在庫・人員の誤差が直接コストになるとき","tone":"blue"},
    {"icon":"📐","title":"RMSE 二乗平均平方根","text":"√平均((実績−予測)²)。大外しを強く罰する。キャパシティ計画","tone":"violet"},
    {"icon":"％","title":"MAPE 平均絶対率誤差","text":"平均(|実績−予測|÷実績)。規模の違うものを比較できる。ただし実績がゼロに近いと爆発する。需要が小さい商品では MAE か sMAPE へ","tone":"green"},
    {"icon":"↕","title":"バイアス 平均誤差","text":"平均(実績−予測)。符号を残す。常に上振れ／下振れしていないかの点検","tone":"amber"} ] }
```
```dax
予測_MAE   := AVERAGEX( VALUES( Dim_日付[年月] ), ABS( [売上合計] - [売上予測] ) )
予測_RMSE  := SQRT( AVERAGEX( VALUES( Dim_日付[年月] ), ( [売上合計] - [売上予測] ) ^ 2 ) )
予測_MAPE  := AVERAGEX( VALUES( Dim_日付[年月] ),
                  DIVIDE( ABS( [売上合計] - [売上予測] ), [売上合計] ) )
予測_バイアス := AVERAGEX( VALUES( Dim_日付[年月] ), [売上合計] - [売上予測] )
```

予測_残差SD :=

        Dim_日付[年月] >= [検証開始月] && Dim_日付[年月] <= [検証終了月] )
RETURN STDEVX.S( 検証期間, [売上合計] - [売上予測] )

売上予測_上限80 := [売上予測] + 1.28 * [予測_残差SD] * SQRT( [予測何期先] )
売上予測_下限80 := [売上予測] - 1.28 * [予測_残差SD] * SQRT( [予測何期先] )
