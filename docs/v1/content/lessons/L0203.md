「Excelはもう使わないほうがいいですか」。答えは**使い続けてください**。ただし役割を分けます。

両者は競合ではなく、設計思想が違う道具です。違いを構造で理解すれば使い分けは自動的に決まります。

    {"title":"Power BI：テーブル指向","tone":"violet","items":[

      "セル単位の書式や数式が存在しない","行が増えても定義は変わらない",

| 観点 | Excel | Power BI |
|---|---|---|
| 得意な行数 | 数万行（上限104万行） | 数百万〜数千万行 |
| 更新の手間 | 毎回手作業で貼り替え | ボタン1回か自動スケジュール |
| 手順の記録 | 人の頭の中かマクロ | 適用したステップに自動記録 |
| 複数表の結合 | VLOOKUPで1表に統合 | 繋いだまま扱う |
| 計算の定義場所 | セルごとに散在 | メジャーとして1か所 |
| 共有 | メール添付で版が乱立 | URLで最新版を全員が見る |
| 自由記入・What-if | 非常に得意 | 苦手 |

> [!NOTE] 決定的な差は再現性
> 価値はグラフの美しさでもデータ量でもない。同じ手順が自動で再現され、人が変わっても同じ数字が出ること。

## まとめ

- Excelはセル指向で自由、Power BIはテーブル指向で厳格
- Power BIの最大の価値は再現性。手順が自動で何度でも実行される
- 移行のサインは「毎月同じ作業」「重い」「版の乱立」「複数ファイルの突合」
- 入力・What-if・その場の集計はExcelが速い。無理に移さない
- VLOOKUPで1枚にせず、表を分けたままリレーションシップで繋ぐ
- ピボットの「値」がメジャーに相当。違いは再利用できるか
- セル結合・多段ヘッダー・色フラグは読み込めない。整然データにする
- 「Excelで分析」で、定義はPower BI・深掘りはExcelの併用ができる
