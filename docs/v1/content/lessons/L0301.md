## つまずいたときの対処

| 症状 | 原因 | 対処 |
|---|---|---|
| Storeでインストールできない | 組織ポリシーでStoreが無効 | ダウンロードセンター版を使う |
| 起動が非常に遅い | 初回起動または低スペック | 2回目以降は速い。8GB未満なら増設 |
| サインインできない | 組織アカウントがない | 未サインインでも作成は可能 |
| 画面が英語で表示される | 表示言語の設定 | オプション → 地域の設定 |
| メニュー位置が教材と違う | バージョン差 | 更新する。リボンの検索で機能名を引く |

> [!DS] 環境の再現性
> 同じCSVでも、バージョンとロケールが違えば結果が変わります。`03/04/2025` は3月4日にも4月3日にもなる。

## まとめ

- Power BI Desktop は無料。Windows専用で、Store版が最も手軽
- macOSは仮想環境・クラウドPC・ブラウザ版Serviceのいずれか
- メモリは16GB以上を推奨。データ量が増えると体感差が大きい
- 初期設定で**「自動の日付/時刻」を必ずオフ**にする
- ロケール設定は日付と小数点の解釈を左右する。チームで揃える
- pbixはOneDrive / SharePointに置くと版履歴が得られる
- 毎月更新される。学習中は最新を維持する

## 理解度チェック（自分に説明してみる）

1. 「自動の日付/時刻」をオフにする理由を、モデルサイズと会計年度の観点で説明してください。
2. 同僚のPCで同じCSVを読んだのに日付が違う。原因と確認すべき設定は。
3. pbixをどこに保存しますか。その利点とリスクを挙げてください。
