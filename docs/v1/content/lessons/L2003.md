## ハルシネーションはなぜ起きるのか

生成AIは「もっともらしい続き」を作ります。存在しない列も仕様も、**同じ自信の強さ**で出力します。


```dax
-- 動くが間違っている例：行ごとの率を平均している
粗利率_誤 = AVERAGE( Fact_売上[粗利率] )

-- 正しい定義：比率は必ず「合計 ÷ 合計」で定義する
粗利率 = DIVIDE( [売上総利益], [売上金額] )
```

小口取引が多いデータでは、この2つは平気で10ポイント以上ずれます。

> [!TRAP] つまずきポイント
> 「Copilotが書いたDAXなので大丈夫だと思った」は事故報告書で最も多い一文です。**生成物の責任は常に提出した人にあります。**
