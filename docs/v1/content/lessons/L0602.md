## 理解度チェック

1. 判定質問を3つ挙げ、`customers.csv` に適用して分類してください。
2. `StandardCost` をファクトに置くべきでない理由を、加法性の観点で説明してください。
3. 「1行＝1受注1商品」の粒度に、受注全体の送料を追加したいと言われました。どう設計しますか。

## よくあるエラーと対処

| 症状 | 原因 | 対処 |
|---|---|---|
| 割引率の合計が300%になる | 非加法的な値を合計した | 割引額と定価を保存しメジャーで割る |
| 在庫の年間合計が異常に大きい | 半加法的な値を日付で合計した | 期末時点を取る DAX に変更する |
| ディメンションの行数がファクトと同じ | 分類または粒度の誤り | 判定質問に戻る。縮退として残す |
| モデルサイズが急に膨らんだ | 伝票番号など一意な列を残した | 要件を確認して削除する |
| 単価をディメンションに置くと合わない | 実売単価は取引ごとに変わる | 定価は Dim_商品、実売単価はファクト |
| 顧客の地域を直したら過去も変わった | SCD Type 1 で運用している | 履歴が必要なら Type 2 を検討する |
