## 相関係数は何を測っているか

ピアソンの r は「直線関係の強さと向き」だけを測ります。

```figure
{ "type":"cards", "cols":4, "title":"相関係数 r の読み方", "caption":"実務では ±0.3〜0.7 が最も多い", "items":[
    {"icon":"↗","title":"+0.7 〜 +1.0","text":"強い正の相関。片方が増えると他方も増える","tone":"green"},
    {"icon":"➚","title":"+0.3 〜 +0.7","text":"中程度。この範囲の解釈が実務の腕の見せどころ","tone":"blue"},
    {"icon":"→","title":"−0.3 〜 +0.3","text":"ほぼ無相関。ただし非線形の可能性を必ず確認","tone":"gray"},
    {"icon":"↘","title":"−1.0 〜 −0.7","text":"強い負の相関。片方が増えると他方は減る","tone":"amber"} ] }
```
```figure
{ "type":"compare", "title":"相関係数が見落とすもの", "caption":"どちらも散布図と層別で見つかる",
  "panels":[
    {"title":"r が低くても関係はある","tone":"amber","note":"散布図を見れば一目",
     "items":["U字・逆U字（適温を超えると落ちる）","閾値のある関係（在庫が割ると欠品が急増）","周期的な関係（曜日・季節）"]},
    {"title":"r が高くても関係はない","tone":"bad","note":"散布図＋層別で点検",
     "items":["外れ値1点が直線を作っている","両方が時間とともに増えているだけ","集約データで計算した（エコロジカル相関）","第三の変数（交絡）を経由している"]} ] }
```
```dax
相関係数_広告費と売上 :=
VAR T = ADDCOLUMNS( VALUES( Dim_店舗[店舗ID] ),
        "@X", CALCULATE( SUM( Fact_月次[広告費] ) ),
        "@Y", CALCULATE( SUM( Fact_月次[売上] ) ) )
VAR N  = COUNTROWS( T )
VAR MX = AVERAGEX( T, [@X] )
VAR MY = AVERAGEX( T, [@Y] )
VAR Cov = SUMX( T, ( [@X] - MX ) * ( [@Y] - MY ) )
VAR SX  = SQRT( SUMX( T, ( [@X] - MX ) ^ 2 ) )
VAR SY  = SQRT( SUMX( T, ( [@Y] - MY ) ^ 2 ) )
RETURN IF( N >= 3, DIVIDE( Cov, SX * SY ) )
```
```figure
{ "type":"formula", "lang":"dax", "title":"相関係数の正体", "code":"DIVIDE( Cov, SX * SY )",
  "parts":[
    {"match":"Cov","label":"共分散。2変数が同じ方向にずれる量の合計","tone":"amber"},
    {"match":"SX * SY","label":"各変数のばらつきの積。割ることで単位が消え −1〜+1 に収まる","tone":"blue"} ] }
```
> [!TRAP] 集約すると相関は水増しされる
> 個人で 0.35 の相関が、県別平均では 0.8 超になる。個人の話として語らない。
