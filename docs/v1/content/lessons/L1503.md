## 季節指数と前年同月比

季節指数は「その月は年平均の何%か」です。

```dax
季節指数 :=
VAR 月平均 = CALCULATE( AVERAGEX( VALUES( Dim_日付[年月] ), [売上合計] ),
        ALLEXCEPT( Dim_日付, Dim_日付[月番号] ) )
VAR 全体平均 = CALCULATE( AVERAGEX( VALUES( Dim_日付[年月] ), [売上合計] ),
        REMOVEFILTERS( Dim_日付 ) )
RETURN DIVIDE( 月平均, 全体平均 )

売上_季節調整済 := DIVIDE( [売上合計], [季節指数] )
```

```dax
売上_Zスコア =
VAR 窓 = DATESINPERIOD( Dim_日付[日付], MAX( Dim_日付[日付] ) - 1, -28, DAY )
VAR 平均 = CALCULATE( AVERAGEX( VALUES( Dim_日付[日付] ), [売上合計] ), 窓 )
VAR 偏差 = SQRT( DIVIDE(
        CALCULATE( SUMX( VALUES( Dim_日付[日付] ), ( [売上合計] - 平均 ) ^ 2 ), 窓 ), 28 ) )
RETURN DIVIDE( [売上合計] - 平均, 偏差 )
```
