Q&A は「自然言語で質問できる機能」ではありません。**あなたが整備した語彙の範囲内でだけ質問できる機能**です。

素のモデルに置くと「今月の粗利は？」に答えが返らず、利用者は二度と使いません。逆に語彙を整備すれば、レポートを開かない層が自分の言葉で数字を取りに来ます。

Q&A が参照するのは**モデルのメタデータ**（テーブル名・列名・メジャー名・データ型・リレーションシップ・同義語）です。だから「名前の整備」が本体になります。

```dax
売上コメント =
VAR YoY = DIVIDE( [売上合計] - [売上合計_前年同月], [売上合計_前年同月] )
RETURN
SWITCH(
    TRUE(),
    ISBLANK( [売上合計] ), "対象期間のデータがありません",
    YoY >= 0.05,  "前年を大きく上回っています（+" & FORMAT( YoY, "0.0%" ) & "）",
    YoY >= 0,     "前年並みで推移しています（+" & FORMAT( YoY, "0.0%" ) & "）",
    YoY >= -0.05, "やや前年割れです（" & FORMAT( YoY, "0.0%" ) & "）",
    "前年を大きく下回っています（" & FORMAT( YoY, "0.0%" ) & "）"
)
```

自由入力は「何を聞けばいいか分からない」で止まります。よく使う質問を5〜8本ボタン化し、慣れた人だけ自由入力へ進ませます。

| 症状 | 主な原因 | 対処 |
|---|---|---|
| 「理解できません」が多い | 同義語が未登録／技術的な列名のまま | 表示名の変更と同義語の一括登録 |
| 数字がレポートと合わない | 別のメジャーや列が選ばれている | 重複メジャーの整理、不要フィールドの除外 |
| 「今月」を解釈できない | 日付テーブルが無い／未マーク | 日付テーブルを作成しリレーションを設定 |
| 変なビジュアルで返る | 数値が文字列などデータ型が不適切 | モデルの型を修正 |
| 人によって答えが違う | RLS が効いている（正常動作） | 仕様として説明し、RLS前提でテストする |
| 合計か平均か意図と違う | 列を直接集計している | メジャーを作り、列の既定集計を「なし」にする |

> [!TIP] 実務のコツ
> **暗黙のメジャーを無くす**。列を直接ドラッグして自動集計させず、必要な集計はすべて名前付きメジャーにする。Q&AもCopilotも回答が劇的に安定します。

## 理解度チェック

1. 「Q&Aで『粗利』と聞いても答えが返らない」の原因を3つ挙げ、確認する順番は。
2. 「件数」を `[受注件数]` と `[出荷件数]` の両方に登録するとどうなるか。回避策は。
3. ナラティブの自動生成文をそのまま経営向けに載せてはいけない理由と、代替策2つ。
