売上_トップN =
VAR N = 10
VAR Ranked = RANKX( ALLSELECTED( Dim_商品[ProductName] ), [売上合計], , DESC )
RETURN IF( Ranked <= N, [売上合計] )

売上_その他 =
VAR N = 10
VAR TotalSales = CALCULATE( [売上合計], ALLSELECTED( Dim_商品[ProductName] ) )
VAR TopSales =
    SUMX( TOPN( N, ADDCOLUMNS( ALLSELECTED( Dim_商品[ProductName] ), "@売上", [売上合計] ), [@売上], DESC ), [@売上] )
RETURN TotalSales - TopSales

## 理解度チェック

**問1.** 18個のビジュアルで初回表示9秒。まず何をするか。

<details>
<summary>解答</summary>
記録を取り時間の降順に並べる。全部ではなく上位1〜2個に集中する。
</details>

**問2.** 増分更新を設定したのに更新時間が変わらない。何を確認するか。

<details>
<summary>解答</summary>
クエリの折りたたみ。ネイティブクエリの表示が有効かを確認する。
</details>

**問3.** 集計テーブルを足したのに明細がスキャンされる。原因は。

<details>
<summary>解答</summary>
要求粒度が集計より細かい、または集計の管理の列マッピングが不完全。
</details>
