Power Query は**データを加工しません。加工の手順を記録します**。
その台本が **適用したステップ** です。

> [!NOTE]
> 「データを直す」ではなく「直す手順を書く」。
> この違いが以降すべての操作の意味を決めます。

## 適用したステップの正体

ステップ1行は M言語のコード1行。詳細エディターで全体が読めます。

```m
let
    ソース = Csv.Document(File.Contents("C:\data\sales.csv"), [Delimiter=",", Encoding=65001]),
    昇格されたヘッダー数 = Table.PromoteHeaders(ソース, [PromoteAllScalars=true]),
    変更された型 = Table.TransformColumnTypes(昇格されたヘッダー数,
        {{"OrderID", type text}, {"OrderDate", type date}, {"Quantity", Int64.Type}}),
    フィルターされた行 = Table.SelectRows(変更された型, each [Quantity] > 0)
in
    フィルターされた行
```

日付や小数の変換が失敗したら、ロケールを明示します。
```m
= Table.TransformColumnTypes(前のステップ, {{"受注日", type date}}, "ja-JP")
```

- 型変換ステップは1つに集約し、変えたいときは中身を編集する
- 列名の変更は破壊的変更。改名ステップを先頭に置くと復旧が速い
- 行数の確認は「変換 → 行数のカウント」を一時的に足すのが確実

> [!TIP]
> ステップ名は目的で書く。「小計行を除外」なら意図が残ります。
> M の変数名も同時に変わり、詳細エディターも読みやすくなります。

## よくあるエラーと対処

| 症状 | 原因 | 対処 |
|---|---|---|
| 列 'XXX' は見つかりません | 参照中の列を削除・改名した | 歯車から列を選び直す／改名ステップを先頭に置く |
| 消したら以降が全部エラー | 後続が結果に依存している | Ctrl+Z で戻し、最後尾のステップから順に消す |
| 更新が異常に遅い | 折りたたみが早く切れた | ネイティブクエリで境界を特定し、絞り込みを前へ |
| プレビューと行数が違う | プレビューは先頭のみ | 「行数のカウント」で確認し、後で削除する |
| 同名ステップが増え続ける | 既定名のまま操作した | 右クリック → 名前の変更で目的を書く |
