| 基数 | 意味 | 使用頻度 |
|---|---|---|
| 1対多 / 多対1 | 片方で一意、もう片方で重複。同じ関係を逆から見た表記 | ほぼすべて |
| 1対1 | 両方で一意。テーブル統合を検討すべきサイン | まれ |
| 多対多 | 両方で重複。ブリッジテーブルで解消する | 例外的 |

## 理解度チェック

1. 基数が多対多になりました。最も可能性の高い原因と、確認手順を2つ挙げてください。
2. カテゴリ別売上に「(空白) 48,000円」が出ました。正しい対処とやってはいけない対処を述べてください。
3. `OrderDate` と `ShipDate` の両方で分析する実装を、DAX を含めて説明してください。

## よくあるエラーと対処

| 症状 | 原因 | 対処 |
|---|---|---|
| 基数が多対多になる | 1側のキーに重複がある | 列の分布で確認し重複削除。粒度を見直す |
| リレーションシップが作れない | キーの型が違う | 両側の型を揃える（IDは text が安全） |
| 「(空白)」行が出る | ファクトのキーがマスタにない | 左反結合で洗い出し、マスタを修正 |
| 売上が全部「(空白)」の月に集まる | 日付列に時刻が入っている | Power Query で date 型に変換する |
| 線が勝手に無効化された | 双方向で経路があいまいになった | 単一方向へ戻し、経路を1本に絞る |
| 2本目の日付の線が点線になる | アクティブは1本までの仕様 | USERELATIONSHIP のメジャーを作る |
| 意図しない線が引かれている | 自動検出が有効 | オプションで自動検出を無効にする |
