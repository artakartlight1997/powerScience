- 解除の前に、残す列と不要な行が確定しているか確認する

## 理解度チェック

1. 「列のピボット解除」と「その他の列のピボット解除」の M の違いと、後者を推す理由は。
2. 属性列 `2025年1月` を日付型にすべき理由を2つ。月初日に統一する利点は何ですか。
3. 元セルが空欄だと解除結果はどうなりますか。それが問題になる分析はどんなときですか。

## よくあるエラーと対処

| 症状 | 原因 | 対処 |
|---|---|---|
| 翌月の列だけ縦持ちにならない | 列を列挙して解除していた | 「その他の列のピボット解除」に置き換える |
| 値列が ABC123（any 型） | 解除対象にテキスト列が混ざった | テキスト列をキー列側へ移す／解除後に型変換 |
| 列に複数の値が含まれています | 列のピボットで集計関数がない | 詳細設定オプションで合計・カウントを選ぶ |
| 月が「10月・11月・1月」順 | 属性列が文字列のまま | 日付型に変換し、日付テーブルと結ぶ |
| 解除後に行数が爆発した | 小計行や注釈行を残して解除した | 解除の前に不要な行を除外する |
| 属性列に「Column7」が混ざる | 見出しのない空列が対象に入った | 解除前に空列を削除する |
