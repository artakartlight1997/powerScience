## ステップ2：ページ①「売上サマリー」（20分）

まず動的タイトル用のメジャーを作ります。

```dax
レポートタイトル =
VAR 期間 =
    FORMAT( MIN( Dim_日付[Date] ), "yyyy年M月" ) & " 〜 " &
    FORMAT( MAX( Dim_日付[Date] ), "yyyy年M月" )
VAR 地域 =
    IF(
        ISFILTERED( Dim_店舗[Region] ),
        CONCATENATEX( VALUES( Dim_店舗[Region] ), Dim_店舗[Region], ", " ),
        "全社"
    )
RETURN
    地域 & " 売上サマリー（" & 期間 & "）"

取引件数 = DISTINCTCOUNT( Fact_売上[OrderID] )
```

## トラブルシューティング

| 症状 | 原因 | 対処 |
|---|---|---|
| テーマを変えても色が戻らない | ビジュアル側で色を個別指定した | 書式 → 既定値に戻す |
| 動的タイトルが「全社」のまま | 相互作用で絞っている | `ISFILTERED` は強調表示を検知しない仕様 |
| 条件付き書式にメジャーが出ない | 書式スタイルがグラデーション | 「フィールド値」に切り替える |
| ドリルスルーで戻れない | 戻るボタンを削除した | 挿入 → ボタン → 戻る で再追加 |
| ツールチップが出ない | ページの種類が違う | キャンバスの設定を確認 |
| モバイルで文字が読めない | そのページが未設定 | 全ページに設定 |
| 表示が10秒以上かかる | ビジュアルが多い／メジャーが重い | [LAB09](lab.html?id=LAB09) で計測 |

## 発展課題

### 課題1：表示切り替えボタン（15分）

1. マトリックスと横棒グラフを同じ位置に重ねて配置する
2. **表示 → 選択** で片方を非表示にし、ブックマーク①を保存（「データ」のチェックは外す）
3. 逆の状態でブックマーク②を保存する
4. ボタンを2つ置き、それぞれにブックマークを割り当てる

「データ」を外さないと、保存時のスライサー選択まで復元されてしまいます。

### 課題2：What-if パラメーターで目標を動かす（15分）

1. **モデリング → 新しいパラメーター → 数値範囲**、名前 `目標成長率`、最小0・最大0.3・増分0.01
2. 次の2本を作り、スライダーで達成率が動くことを確認する

```dax
目標売上 = CALCULATE( [総売上], SAMEPERIODLASTYEAR( Dim_日付[Date] ) ) * ( 1 + [目標成長率 値] )

目標達成率 = DIVIDE( [総売上], [目標売上] )
```

### 課題3：レビューを受ける（20分）

Power BI を知らない人に10秒だけ見せて、次の3つを聞きます。

1. この画面から何が分かりますか
2. 一番大きい数字はどれですか
3. 明日何をすればいいと思いますか

3つ目に答えられなければ「使われるレポート」ではありません。設計論は [LAB11](lab.html?id=LAB11) で扱います。
