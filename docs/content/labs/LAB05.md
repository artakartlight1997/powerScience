## ステップ3：ページ①「売上サマリー」（20分）

### 動的タイトルを作る

まず次のメジャーを作成します。

```dax
レポートタイトル =
VAR 期間 =
    FORMAT( MIN( Dim_日付[Date] ), "yyyy年M月" ) & " 〜 " &
    FORMAT( MAX( Dim_日付[Date] ), "yyyy年M月" )
VAR 地域 =
    IF(
        ISFILTERED( Dim_店舗[Region] ),
        CONCATENATEX( VALUES( Dim_店舗[Region] ), Dim_店舗[Region], ", " ),
        "全社"
    )
RETURN
    地域 & " 売上サマリー（" & 期間 & "）"
```

**カード**ビジュアルにこのメジャーを入れ、ページ最上部に配置します。フォントサイズは20pt程度、カテゴリラベルはオフにします。

> [!TIP] 動的タイトルの効果
> レポートを PDF や画像で共有したとき、「これはどの期間・どの地域の数字か」が本文に焼き込まれます。スクリーンショットが独り歩きしても誤解されません。

### KPIカードを4つ

余白をクリック → **カード** で以下を作成し、横一列に配置します。

| 位置 | メジャー | 書式 |
|---|---|---|
| 1 | 総売上 | 桁区切り・小数0桁 |
| 2 | 粗利率 | パーセント・小数1桁 |
| 3 | 前年比増減率 | パーセント・小数1桁 |
| 4 | 取引件数 | 桁区切り・小数0桁 |

`取引件数` がなければ次を作成します。

```dax
取引件数 = DISTINCTCOUNT( Fact_売上[OrderID] )
```

4つを選択して **書式（リボン）→ 配置 → 上揃え**、続いて **横方向に均等配置**。

### 月次推移の折れ線

- X軸：`Dim_日付[年月]`
- Y軸：`総売上`
- **分析ペイン → 平均線** を追加（点線・薄いグレー）
- 2本目の線として `売上_7日移動平均` を追加してもよい

### 地域別売上（横棒）

- Y軸：`Dim_店舗[Region]`
- X軸：`総売上`
- 「…」→ 軸の並べ替え → 総売上 → 降順
- 書式 → データラベル：オン

### カテゴリ構成（積み上げ横棒）

- Y軸：`Dim_日付[年]`
- X軸：`総売上`
- 凡例：`Dim_商品[Category]`

### スライサー

右側または上部に3つ配置します。

| スライサー | フィールド | スタイル |
|---|---|---|
| 年度 | `Dim_日付[年度]` | タイル |
| 地域 | `Dim_店舗[Region]` | ドロップダウン |
| カテゴリ | `Dim_商品[Category]` | ドロップダウン |

> [!TRAP] スライサーの位置が毎ページ違う
> ページを移動するたびにスライサーを探すレポートは使われなくなります。**全ページで同じ位置**に置いてください。さらに **書式 → スライサーの同期** を使えば、ページをまたいで選択状態を引き継げます。

### 相互作用の調整

KPIカードを選択 → **書式（リボン）→ 相互作用の編集**。棒グラフからカードへの影響を「フィルター」に設定します（既定で強調表示になっている場合があります）。

## ステップ5：ページ③「商品詳細」（ドリルスルー）（10分）

新しいページを追加し、名前を「商品詳細」にします。

1. 視覚化ペインの **ページ情報の下 → ドリルスルー** に `Dim_商品[ProductName]` をドラッグ
2. 「すべてのフィルターを保持」をオンにする
3. 自動生成された戻るボタンはそのまま残す
4. 動的タイトル用のメジャーを作成

```dax
商品詳細タイトル =
SELECTEDVALUE( Dim_商品[ProductName], "商品を選択してください" )
```

5. 配置するビジュアル
   - カード：`商品詳細タイトル`（見出しとして使う）
   - カード：`総売上`、`粗利率`、`商品ランク`
   - 折れ線：`Dim_日付[年月]` × `総売上`
   - 横棒：`Dim_店舗[StoreName]` × `総売上`
   - 横棒：`Dim_顧客[Segment]` × `総売上`

動作確認：ページ②のマトリックスで商品名を右クリック → **ドリルスルー → 商品詳細** を選択します。

> [!TRAP] ドリルスルーが右クリックメニューに出ない
> ドリルスルーフィールド（`ProductName`）が、ドリルスルー元のビジュアルに含まれていない可能性があります。マトリックスを `Category` レベルまでしか展開していないと出ません。商品名の行まで展開してから右クリックしてください。

## ステップ9：アクセシビリティの仕上げ（5分）

1. 各ビジュアルを選択 → **書式 → 全般 → 代替テキスト** に説明を入力

## トラブルシューティング

| 症状 | 原因 | 対処 |
|---|---|---|
| テーマを変えても色が戻らない | ビジュアル側で色を個別指定した | 書式 → 既定値に戻す |
| 動的タイトルが「全社」のまま | スライサーではなく相互作用で絞っている | `ISFILTERED` は他ビジュアルの強調表示を検知しない。仕様 |
| 条件付き書式にメジャーが出ない | 書式スタイルが「グラデーション」のまま | 「フィールド値」に切り替える |
| ドリルスルーで戻れない | 戻るボタンを削除した | 挿入 → ボタン → 戻る で再追加 |
| ツールチップが出ない | ページの種類がツールチップになっていない | キャンバスの設定を確認 |
| ナビゲーターに隠しページが出る | 「非表示のページを表示しない」がオフ | 書式から有効化 |
| モバイルで文字が読めない | そのページのモバイルレイアウト未設定 | 全ページに設定 |
| 表示が10秒以上かかる | ビジュアルが多すぎる／メジャーが重い | [LAB09](lab.html?id=LAB09) で計測して直す |

## 発展課題

### 課題1：表示切り替えボタン（15分）

1. マトリックスと横棒グラフを同じ位置に重ねて配置
2. **表示 → 選択** で片方を非表示にし、ブックマーク①を保存（「データ」のチェックは外す）
3. 逆の状態でブックマーク②を保存
4. ボタンを2つ配置し、それぞれにブックマークを割り当てる

> [!TRAP] ブックマークで「データ」のチェックを外す理由
> オンのままだと、ブックマークを保存したときのスライサー選択状態まで復元されます。ユーザーが選んだ条件が勝手に戻る、という最悪の体験になります。表示切り替えだけが目的なら必ず外してください。

### 課題2：What-if パラメーターで目標を動かす（15分）

1. **モデリング → 新しいパラメーター → 数値範囲**、名前 `目標成長率`、最小0・最大0.3・増分0.01
2. 次のメジャーを作る

```dax
目標売上 = CALCULATE( [総売上], SAMEPERIODLASTYEAR( Dim_日付[Date] ) ) * ( 1 + [目標成長率 値] )
```

```dax
目標達成率 = DIVIDE( [総売上], [目標売上] )
```

3. スライダーを動かすと、達成率が連動して変わることを確認する

### 課題3：レビューを受ける（20分）

作ったレポートを、Power BI を知らない人に見せて次を聞いてください。

1. この画面から何が分かりますか（10秒だけ見せて）
2. 一番大きい数字はどれですか
3. 明日何をすればいいと思いますか

3つ目に答えられないなら、それは「見られるレポート」であって「使われるレポート」ではありません。設計の作法は [LAB11](lab.html?id=LAB11) で本格的に扱います。
