## フェーズ1：取得と整形（0〜25分 / 30点）

### 課題1-1：4ファイルを読み込む（8点）

- 4つのCSVを読み込み、クエリ名を `Fact_売上` `Dim_商品` `Dim_顧客` `Dim_店舗` にする
- すべての列に明示的な型を設定する
- 自動で追加された「変更された型」ステップは削除し、自分で設定し直す

### 課題1-2：品質を確認する（6点）

- 列の品質・列の分布・列のプロファイルをオンにする
- ステータスバーで「データセット全体に基づく」に切り替える
- `Fact_売上` にエラー行・空行がないことを確認する

### 課題1-3：不要な列を落とす（6点）

- `Dim_店舗[Manager]` を削除（`ManagerEmail` は残す）
- `Fact_売上[ShipDate]` は残す（非アクティブなリレーションシップで使う）

### 課題1-4：派生列を作る（10点）

`Fact_売上` に、列の追加で次を作成します。

| 列名 | 内容 |
|---|---|
| `値引前金額` | `Quantity` × `UnitPrice` ÷ ( 1 − `Discount` ) を四捨五入 |
| `出荷日数` | `ShipDate` − `OrderDate` の日数 |

`出荷日数` は **列の追加 → 日付の減算** でも作れますが、カスタム列なら次のとおりです。

```m
= Duration.Days( [ShipDate] - [OrderDate] )
```

> [!TRAP] 値引前金額の計算
> `UnitPrice` は既に値引後の単価です。定価に戻すには除算が必要で、`Discount` が 1 になると 0 除算になります。実データに 1 はありませんが、**割り算の前に分母を確認する**習慣を付けてください。M言語なら次のように書きます。
> `= if [Discount] >= 1 then null else Number.Round( [Quantity] * [UnitPrice] / ( 1 - [Discount] ), 0 )`

## フェーズ3：DAX（50〜80分 / 27点）

`_Measures` テーブルを作り、次の9本を実装します。各3点。

| # | メジャー | 要件 |
|---|---|---|
| 1 | `総売上` | `SalesAmount` の合計 |
| 2 | `販売数量` | `Quantity` の合計 |
| 3 | `取引件数` | `OrderID` の一意な数 |
| 4 | `粗利` | 売上 − 原価（`StandardCost` × `Quantity`） |
| 5 | `粗利率` | 粗利 ÷ 売上。ゼロ除算対策込み |
| 6 | `前年売上` | 前年同期の売上 |
| 7 | `前年比` | 前年がない期間は空白 |
| 8 | `売上YTD` | 4月始まりの年度累計 |
| 9 | `カテゴリ構成比` | 選択範囲内での構成比 |

```figure
{ "type":"formula", "lang":"dax", "title":"この演習で最も配点が高い型",
  "code":"CALCULATE( [総売上], SAMEPERIODLASTYEAR( Dim_日付[Date] ) )",
  "caption":"CALCULATE + タイムインテリジェンス関数。この形を手が覚えているかが分かれ目",
  "parts":[
    {"match":"CALCULATE","label":"フィルターコンテキストを変更する唯一の関数","tone":"violet"},
    {"match":"[総売上]","label":"変更後のコンテキストで評価する式","tone":"blue"},
    {"match":"SAMEPERIODLASTYEAR( Dim_日付[Date] )","label":"日付フィルターを1年前にずらす","tone":"amber"} ] }
```

すべてに適切な書式（桁区切り／パーセンテージ）を設定してください。書式の設定漏れも減点対象です。

> [!TRAP] 9本を上から順に書かない
> `粗利` は `原価合計` に、`前年比` は `前年売上` に依存します。依存の下にあるメジャーから先に作らないと、参照エラーが出て時間を溶かします。**依存関係の下から順に**作ってください。

## 詰まったときの答え

### フェーズ1

| 詰まり | 答え |
|---|---|
| 型が勝手に変わる | 自動の「変更された型」ステップを削除し、自分で設定する |
| 出荷日数が負になる | `ShipDate` < `OrderDate` の行を確認。データ誤りとして除外するか記録する |
| 値引前金額がエラー | `Discount` が 1 の行での0除算。`if` で分岐する |

### フェーズ2

| 詰まり | 答え |
|---|---|
| 日付テーブルが作れない | `Dim_日付 = CALENDAR( DATE(2024,1,1), DATE(2024,12,31) )` から始め、`ADDCOLUMNS` を後から足す |
| 年度の計算 | `IF( MONTH([Date]) >= 4, YEAR([Date]), YEAR([Date]) - 1 )` |
| 非アクティブな線が作れない | 既にアクティブな線がある場合、2本目は自動で非アクティブになる |

### フェーズ3

| 詰まり | 答え |
|---|---|
| 粗利が計算できない | `SUMX( Fact_売上, Fact_売上[Quantity] * RELATED( Dim_商品[StandardCost] ) )` |
| 前年比が全期間空白 | 日付テーブルとしてマークしていない |
| YTDが1月始まり | `TOTALYTD( [総売上], Dim_日付[Date], "3/31" )` |
| 構成比が100%にならない | `ALLSELECTED( Dim_商品[Category] )` を分母に使う |

### フェーズ4

| 詰まり | 答え |
|---|---|
| 条件付き書式にメジャーが出ない | 書式スタイルを「フィールド値」に変更 |
| ドリルスルーが動かない | ドリルスルー元のビジュアルに `ProductName` が含まれているか確認 |
| モバイルレイアウトの意味 | 表示 → モバイル レイアウト。ページごとに設定 |

### フェーズ5

| 詰まり | 答え |
|---|---|
| RLSで何も見えない | メールアドレスの小文字化と、権限表への存在を確認 |
| RLSで全部見える | ロールのチェックボックスを入れていない |
| 発行先が選べない | 個人用ワークスペースしかない。共有ワークスペースを作成する |
