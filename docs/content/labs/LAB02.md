## ステップ6：重複の除去と年月の日付化（8分）

4. **列の追加 → カスタム列**、列名 `年月日` で次の式を入力

## トラブルシューティング

| 症状 | 原因 | 対処 |
|---|---|---|
| ヘッダーが `Column1` のまま | 1行目をヘッダーにしていない | 変換タブから実行 |
| 型変換でエラーが数十件 | `,` `N/A` の除去より先に型を変えた | 型変換ステップを削除し順序を戻す |
| ピボット解除後に列が7列 | 「選択した列」を使った | 削除してキー2列で「その他の列」 |
| 全角スペースが消えない | 半角を入力していた | 数式バーで直接 `Text.Replace` |
| `Date.FromText` がエラー | 置換結果が `2025-1-01` でない | 置換を分割して中間結果を確認 |
| 重複削除で行が減りすぎた | 1列だけ選択して実行した | 選択を解除して実行し直す |
