## このラボのゴール

[sales_dirty.csv](data/sales_dirty.csv) を、分析可能な整然データ（1行が1つの事実を表す形）に変換します。

このファイルには、次の問題が意図的に含まれています。

| 2 | 月が横持ちの列になっている | ステップ4 |
| 3 | 店舗名に全角スペースが混ざる | ステップ3 |
| 4 | カテゴリ名の末尾に全角スペース | ステップ3 |

## ステップ1：読み込みとヘッダーの修正（5分）

1. **データを取得 → テキスト/CSV** で `sales_dirty.csv` を選択
2. **データの変換** をクリック
3. プレビューを見ると、1行目に「Northstar Retail 月次売上速報（経理部作成）」という余計な行があります
4. **ホーム → 行の削除 → 上位の行の削除 → 1行**
5. **変換 → 1行目をヘッダーとして使用**

これで `店舗名 / 商品カテゴリ / 2025年1月 / 2025年2月 / 2025年3月 / 2025年4月 / 備考` が見出しになりました。

> [!TRAP] 自動で付く「変更された型」ステップ
> 読み込み直後、適用したステップに「変更された型」が自動追加されていることがあります。この段階の型推定は当てになりません。**このステップは削除してください。** 型はステップ5で自分で決めます。

## ステップ2：ゴミ行を除去（5分）

### 小計行を消す

1. `店舗名` 列のフィルターボタン（▼）→ **テキストフィルター → 指定の値を含まない**
2. 「小計」と入力してOK

> [!TIP] 表記ゆれへの備え
> 実務では「小計」の表記が揺れます（「合計」「計」「Total」）。**表示 → 列の品質・列の分布・列のプロファイル** をオンにし、ステータスバーで「データセット全体に基づく」に切り替えてから、実際の値を目で確認して条件を決めてください。

### 空行を消す

**ホーム → 行の削除 → 空白行の削除**

### 備考列を消す

分析に使わないので削除します。`備考` 列を右クリック → **削除**。

> [!NOTE] 「他の列の削除」との使い分け
> 本来は「他の列の削除」で使う列だけを残すほうが安全です（元ファイルに列が増えても壊れない）。ここでは次のピボット解除で残す列が変わるため、不要列の個別削除で進めます。

## ステップ3：文字列のクレンジング（8分）

### 全角スペースを半角に

1. `店舗名` 列を選択 → **変換 → 値の置換**
2. 検索する値：全角スペース（`　`）を入力（IMEで全角空白を入力してください）
3. 置換後：半角スペース（` `）
4. `商品カテゴリ` 列にも同じ操作を行う

> [!TRAP] 全角スペースは目で見つからない
> 全角スペースは幅があるだけの文字で、見た目では判別できません。列プロファイルの「個別の値」を見ると、`家電` と `家電　` が**別々の値として2行に分かれて表示される**ので、そこで存在に気づけます。

### トリミングとクリーン

1. `店舗名` と `商品カテゴリ` を両方選択（Ctrl キー）
2. **変換 → 書式 → トリミング**（前後の空白を除去）
3. 続けて **変換 → 書式 → クリーン**（印字できない制御文字を除去）

### 数式で一括処理する方法

上の3操作は、数式バーで1ステップにまとめられます。適用したステップの最後を選んでから、数式バーに次を貼り付けてください。

```m
= Table.TransformColumns( 前のステップ名, {
    {"店舗名",       each Text.Trim( Text.Replace( _, "　", " " ) ), type text},
    {"商品カテゴリ", each Text.Trim( Text.Replace( _, "　", " " ) ), type text}
  })
```

`前のステップ名` は、適用したステップ一覧に表示されている直前のステップ名（例：`削除された列`）に置き換えます。

```figure
{ "type":"tablediff", "title":"クレンジングの前後", "arrowLabel":"置換 → トリミング → クリーン",
  "caption":"見た目は変わらないが、集計時に別グループへ分かれる事故がなくなる",
  "before":{"title":"クレンジング前","tone":"bad","head":["店舗名","商品カテゴリ"],
    "rows":[["新宿本店","!家電　"],["!　新宿本店 ","衣料"],["渋谷店","食品"]]},
  "after":{"title":"クレンジング後","tone":"good","head":["店舗名","商品カテゴリ"],
    "rows":[["新宿本店","家電"],["新宿本店","衣料"],["渋谷店","食品"]]} }
```

## ステップ4：ピボット解除で縦持ちに（8分）

ここがこのラボの核心です。

1. `店舗名` と `商品カテゴリ` の**2列を選択**（Ctrl キー）
2. 右クリック → **その他の列のピボット解除**

`2025年1月` 〜 `2025年4月` の4列が、`属性` と `値` の2列にまとまりました。

3. `属性` 列を右クリック → **名前の変更** → `年月`
4. `値` 列を → `売上金額`

```figure
{ "type":"tablediff", "title":"ピボット解除の効果", "arrowLabel":"その他の列のピボット解除",
  "caption":"列だった月が「値」になる。5月の列が増えても手を入れずに取り込まれる",
  "before":{"title":"横持ち（分析しにくい）","tone":"bad","head":["店舗名","カテゴリ","2025年1月","2025年2月"],
    "rows":[["新宿本店","家電","283192","2497347"],["渋谷店","衣料","1204880","998120"]]},
  "after":{"title":"縦持ち（整然データ）","tone":"good","head":["店舗名","カテゴリ","年月","売上金額"],
    "rows":[["新宿本店","家電","2025年1月","283192"],["新宿本店","家電","2025年2月","2497347"],["渋谷店","衣料","2025年1月","1204880"]]} }
```

> [!EXAM] 試験で問われる分岐
> **「選択した列のピボット解除」ではなく「その他の列のピボット解除」を使う**のがポイントです。前者は選んだ列だけを対象にするため、5月の列が追加されるとクエリを直す必要があります。後者は「キー列以外すべて」なので自動で追いつきます。PL-300 の「1.5 データの構造化」で頻出です。

## ステップ5：数値のクレンジング（10分）

`売上金額` 列にはまだ問題が残っています。

```figure
{ "type":"cards", "cols":3, "title":"データプロファイリングの3つの道具", "caption":"3つとも常時オンにしておく。整形は「見えている」ことから始まる",
  "items":[
    {"icon":"✅","title":"列の品質","text":"有効・エラー・空の割合を帯で表示する。型変換後のエラー検出に使う","tone":"green"},
    {"icon":"📊","title":"列の分布","text":"個別の値の数と一意の値の数を出す。表記ゆれの発見に使う","tone":"blue"},
    {"icon":"🔍","title":"列のプロファイル","text":"最小・最大・平均と値の一覧を出す。外れ値の発見に使う","tone":"violet"} ] }
```

1. **表示 → 列の品質・列の分布・列のプロファイル** をすべてオン
2. ステータスバーで **「データセット全体に基づく列プロファイル」** に切り替え
3. `売上金額` 列を見ると、`N/A` や桁区切り付きの文字列が混在していることが分かります

### 桁区切りのカンマを除去

`売上金額` 列を選択 → **変換 → 値の置換** → 検索 `,` → 置換後は空欄。

### N/A を null に

同じく **値の置換** → 検索 `N/A` → 置換後は空欄。「詳細設定オプション → セル全体の内容を一致させる」に必ずチェックを入れます。

> [!TRAP] セル全体一致のチェックを忘れると
> チェックを外したまま実行すると、値の一部に `N/A` を含む文字列（例：`N/A確認中`）まで巻き込んで壊します。置換系の操作では常に「セル全体」を意識してください。

### 型を整数に変換

1. `売上金額` 列の型アイコン → **整数**
2. 列の品質でエラーが0件であることを確認する
3. エラーが残っている場合、列見出しの赤い帯をクリック → **エラーの表示** で原因行だけを抽出できます

### 空欄の扱いを決める

「売上がない」のか「データが未入力」なのかで対応が変わります。

| 判断 | 操作 | 意味 |
|---|---|---|
| 売上ゼロとみなす | 値の置換で null → 0 | 「0円の実績があった」 |
| データなしとして集計から除外 | そのまま null にしておく | 「実績が記録されていない」 |
| 行ごと不要 | ホーム → 行の削除 → 空白行の削除 | 「この行は存在しない」 |

```figure
{ "type":"compare", "title":"null を残す / 0 で埋める", "caption":"どちらが正しいかはデータの意味で決まる。迷ったら残す",
  "panels":[
    {"title":"null のまま残す","tone":"good",
     "items":["SUM は無視するので合計は正しい","AVERAGE の分母に入らない","「未記録」と「0円」を区別できる"],
     "note":"このラボの選択"},
    {"title":"0 で埋める","tone":"bad",
     "items":["平均が実態より低く出る","最小値が常に0になる","「0円の実績」という嘘の事実が生まれる"],
     "note":"意味を確認せずに使わない"} ] }
```

> [!WARN] このラボでは null のまま残す
> `SUM` は null を無視するため、合計は正しく出ます。0 に置き換えると平均（`AVERAGE`）の分母に入り、**平均が実態より低く出ます**。「0で埋めておけば安全」は誤りです。

## ステップ6：重複の除去（3分）

1. **ホーム → 行の削除 → 重複の削除**（列を選択せずに実行すると全列一致の行が対象）
2. 削除前後で行数を確認する（ステータスバー右下に表示されます）

> [!TIP] 消す前に数える
> 重複を消す前に、**ホーム → 行の保持 → 重複の保持** を一時的に実行すると、何が重複しているかを確認できます。確認したらそのステップを削除して、本来の重複削除に進みます。「消してから気づく」を避ける習慣です。

## ステップ7：年月を日付に変換（5分）

`2025年1月` という文字列のままでは、時系列の並べ替えも前年比もできません。

1. **列の追加 → カスタム列**、列名 `年月日`

```m
= Date.FromText(
    Text.Replace( Text.Replace( [年月], "年", "-" ), "月", "-01" )
  )
```

2. 型を **日付** に設定する
3. 元の `年月` 列は表示用として残して構いません

変換の流れは `2025年1月` → `2025-1-01` → 日付、です。

> [!TIP] うまくいかないときの切り分け
> カスタム列を2つに分けてください。まず `= Text.Replace( Text.Replace( [年月], "年", "-" ), "月", "-01" )` だけの列を作り、文字列が期待どおりかを目で確認します。確認できたら `Date.FromText(...)` で囲む。**1ステップに2つの処理を詰め込まない**のがデバッグの基本です。

## トラブルシューティング

| 症状 | 原因 | 対処 |
|---|---|---|
| ヘッダーが `Column1` のまま | 「1行目をヘッダーとして使用」を実行していない | 変換タブから実行 |
| 型変換でエラーが数十件 | `,` や `N/A` の除去より先に型を変えた | 型変換ステップを削除し、順序を入れ替える |
| ピボット解除後に列が7列ある | 「選択した列のピボット解除」を使った | ステップを削除し、キー2列を選んで「その他の列」で実行 |
| 全角スペースが消えない | 半角スペースを入力していた | 数式バーで `Text.Replace( _, "　", " " )` を直接書く |
| `Date.FromText` がエラー | 置換結果が `2025-1-01` になっていない | 置換ステップを分割して中間結果を確認 |
| 重複削除で行が減りすぎた | 意図せず1列だけ選択して実行した | 列選択を解除してから実行し直す |
| 閉じて適用でエラー | クエリ名に使えない文字が含まれる | 記号を使わない名前に変更 |

## 発展課題

### 課題1：列が増えても壊れないことを確認する（10分）

### 課題2：ディメンションを切り出す（15分）

配布先でパスが変わっても、パラメーターの値を1つ直すだけで済みます。本格的な実装は [LAB07](lab.html?id=LAB07) で扱います。
