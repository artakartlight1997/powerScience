## メジャー専用テーブルを作る（5分）

メジャーが増えるので、先に置き場所を用意します。

1. **ホーム → データの入力**
2. 列1に何も入力せず、テーブル名を `_Measures` にして「読み込む」
3. 作成後、`Column1` を右クリック → **レポートビューでは非表示**

以降、メジャーを作ったら **メジャーツール → ホームテーブル** で `_Measures` に移動します。

## 1本目：総売上（3分）

```dax
総売上 = SUM( Fact_売上[SalesAmount] )
```

書式：10進数、小数点0桁、桁区切りオン

## 2本目：原価合計（5分）

売上テーブルには原価がありません。商品マスタの `StandardCost` を参照します。

```dax
原価合計 =
SUMX(
    Fact_売上,
    Fact_売上[Quantity] * RELATED( Dim_商品[StandardCost] )
)
```

> [!TIP]
> `RELATED` は多側（Fact_売上）から1側（Dim_商品）の列を取得します。`SUMX` が行コンテキストを作っているので使えます。メジャーの中でいきなり `RELATED` は使えません。

## 3本目：粗利（1分）

```dax
粗利 = [総売上] - [原価合計]
```

## 4本目：粗利率（2分）

```dax
粗利率 = DIVIDE( [粗利], [総売上] )
```

書式：パーセンテージ、小数点1桁

> [!TRAP]
> `/` ではなく `DIVIDE` を使ってください。売上が0の行（フィルター結果が空の場合など）でエラーになりません。

## 5本目：前年同期売上（5分）

```dax
前年売上 = CALCULATE( [総売上], SAMEPERIODLASTYEAR( Dim_日付[Date] ) )
```

確認：マトリックスに `Dim_日付[年]` × `Dim_日付[月]` を置き、`総売上` と `前年売上` を並べます。2024年の行では `前年売上` が空白になるはずです（2023年のデータがないため）。

## 6本目：前年比増減率（5分）

```dax
前年比増減率 =
VAR 今年 = [総売上]
VAR 前年 = [前年売上]
RETURN
    IF(
        ISBLANK( 前年 ) || 前年 = 0,
        BLANK(),
        DIVIDE( 今年 - 前年, 前年 )
    )
```

書式：パーセンテージ、小数点1桁

> [!TIP]
> `BLANK()` を返すようにすることで、前年データがない期間にグラフが跳ねるのを防げます。0を返すと折れ線が0まで落ちて誤解を招きます。

## 7本目：年度累計（YTD）（5分）

Northstar Retail は4月始まりの会計年度とします。

```dax
売上YTD = TOTALYTD( [総売上], Dim_日付[Date], "3/31" )
```

確認：マトリックスに `Dim_日付[年度]` × `Dim_日付[月]` を置き、4月から累積していくことを確認します。

## 8本目：カテゴリ構成比（8分）

```dax
カテゴリ構成比 =
DIVIDE(
    [総売上],
    CALCULATE( [総売上], ALLSELECTED( Dim_商品[Category] ) )
)
```

書式：パーセンテージ、小数点1桁

### 実験：ALL と ALLSELECTED の違いを見る

比較用にもう1本作ります。

```dax
カテゴリ構成比_ALL =
DIVIDE( [総売上], CALCULATE( [総売上], ALL( Dim_商品[Category] ) ) )
```

テーブルに `Category`・`カテゴリ構成比`・`カテゴリ構成比_ALL` を並べ、カテゴリスライサーで2つだけ選んでみてください。

| メジャー | 選択した2カテゴリの合計 |
|---|---|
| カテゴリ構成比（ALLSELECTED） | 100% |
| カテゴリ構成比_ALL（ALL） | 100%未満 |

この違いが体感できたら、[L303](lesson.html?id=L303) の理解は十分です。

## 9本目：売上ランキング（8分）

```dax
商品ランク =
IF(
    ISBLANK( [総売上] ),
    BLANK(),
    RANKX( ALL( Dim_商品[ProductName] ), [総売上], , DESC, DENSE )
)
```

> [!TRAP]
> 第1引数の `ALL` を忘れると全商品が1位になります。RANKXでもっとも多いミスです。`ISBLANK` のチェックは、売上のない商品にランクを付けないためです。

## 10本目：累計売上（Running Total）（8分）

```dax
売上累計 =
VAR 現在日付 = MAX( Dim_日付[Date] )
RETURN
    CALCULATE(
        [総売上],
        Dim_日付[Date] <= 現在日付,
        ALL( Dim_日付 )
    )
```

確認：折れ線グラフのX軸に `Dim_日付[年月]`、Y軸に `売上累計` を置くと、右肩上がりの線になります。

> [!TIP]
> `VAR 現在日付` で外側のコンテキストの日付を保持し、`ALL( Dim_日付 )` で日付フィルターを解除してから「その日以下」を再適用する——この3手順が累計の定石です。

### 12本目：新規顧客数

```dax
新規顧客数 =
VAR 期間開始 = MIN( Dim_日付[Date] )
VAR 現在顧客 = VALUES( Fact_売上[CustomerID] )
VAR 過去顧客 =
    CALCULATETABLE(
        VALUES( Fact_売上[CustomerID] ),
        Dim_日付[Date] < 期間開始,
        ALL( Dim_日付 )
    )
RETURN
    COUNTROWS( EXCEPT( 現在顧客, 過去顧客 ) )
```

### 13本目：7日移動平均

```dax
売上_7日移動平均 =
AVERAGEX(
    DATESINPERIOD( Dim_日付[Date], MAX( Dim_日付[Date] ), -7, DAY ),
    [総売上]
)
```

### 14本目：値引きによる損失額

```dax
値引額 =
SUMX(
    Fact_売上,
    Fact_売上[Quantity] * ( RELATED( Dim_商品[ListPrice] ) - Fact_売上[UnitPrice] )
)
```

### 15本目：達成状況の色（条件付き書式用）

```dax
前年比_色 =
VAR 率 = [前年比増減率]
RETURN
    SWITCH( TRUE(),
        ISBLANK( 率 ),  "#8A93A6",
        率 >= 0.1,      "#14926B",
        率 >= 0,        "#8FBF5A",
        率 >= -0.1,     "#C77700",
        "#D33A4B"
    )
```

テーブルビジュアルで `前年比増減率` の書式 → **条件付き書式 → フォントの色 → フィールド基準** にこのメジャーを指定してください。

## トラブルシューティング

| 症状 | 原因 |
|---|---|
| `RELATED` でエラー | リレーションシップがない、または方向が逆 |
| 前年売上が全部空白 | 日付テーブルとしてマークしていない |
| 累計が累計にならない | `ALL( Dim_日付 )` を忘れている |
| ランクが全部1 | `RANKX` の第1引数に `ALL` がない |
| 構成比が全部100% | 分母のCALCULATEでフィルターを解除できていない |
