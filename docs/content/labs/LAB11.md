所要90分。ビジュアルの作り方ではなく、何を載せるかを決める方法を扱います。

## トラブルシューティング
| 症状 | 原因 | 対処 |
|---|---|---|
| 要件が固まらない | Q3（何を決めるか）を聞いていない | 決定を1つに絞ってもらう |
| 指標が20個になる | 依頼を全部受けた | 打ち手のない指標を落とす |
| 画面が詰まって読めない | 情報階層を決めずに配置した | ワイヤーフレームから描き直す |
| 依頼者が判断できない | しきい値がない | アラート条件を要件シートで確定する |
| 「Excelのほうが早い」 | 既存の見方を無視した | Q5で見せてもらった列を再確認 |
| 使われなくなった | 意思決定のタイミングと合わない | 更新時刻と閲覧時刻を合わせる |
| 追加依頼が止まらない | 目的が拡張し続けている | 別レポートとして切り出す |
