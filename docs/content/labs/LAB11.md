所要90分。ビジュアルの作り方ではなく、**何を載せるかを決める方法**を扱います。技術的に完璧でも使われないレポートと、素朴でも毎朝開かれるレポートを分けるのはここです。

### ヒアリング結果（このラボの設定）

| 項目 | 内容 |
|---|---|
| 主要利用者 | 営業本部長（1名）、エリアマネージャ（4名） |

### 載せる指標を決める

分解した中から、**このレポートに載せるもの**を選びます。全部載せてはいけません。

| 指標 | 載せる | 理由 |
|---|---|---|
| 総売上 | ○ | 目的そのもの |
| 前年比 | ○ | 良し悪しの判断基準 |
| 目標達成率 | ○ | アラート条件 |
| 粗利率 | ○ | 売上だけで判断すると値引きに走るため |
| 新規顧客数 | ○ | 予算配分の判断材料 |
| 客単価 | △ | 詳細ページに置く |
| 購入回数 | × | 今回の意思決定に使わない |
| 在庫回転率 | × | 所管が違う |

> [!TIP] 指標は「7±2」まで
> 1画面で人が同時に把握できる数字は多くありません。**1画面のKPIは4つまで、グラフは4つまで**を目安にしてください。それ以上は詳細ページに逃がします。載せない判断のほうが、載せる判断より価値があります。

### ワイヤーフレームの描き方

1. A4を横に置き、上から4:3:3の比率で3本の横線を引く
2. 一番上の帯に、KPIカードの四角を4つ描く（左から重要な順）
3. 真ん中の帯に、折れ線とエリア別横棒を描く
4. 一番下の帯に、詳細テーブルまたは散布図を描く
5. 右端または上端にスライサーの位置を描く
6. **各四角に「この数字を見て何を判断するか」を書き込む**

6番が肝心です。判断が書けない四角は、削ってください。

> [!WARN] ワイヤーフレームを飛ばすとどうなるか
> Power BI 上でビジュアルを置きながら考えると、「置いてしまったから残す」という判断が働きます。紙なら消しゴムで消せます。**設計の試行錯誤は、実装コストがゼロの場所でやる**のが鉄則です。

### 5秒テストの設計

「5秒層」は、次の3条件を満たすように設計します。

| 条件 | 実装 |
|---|---|
| 良し悪しが色で分かる | 条件付き書式（`達成率_色` メジャー） |
| 変化の方向が記号で分かる | ▲▼ を含む文字列メジャー |
| 対象期間が明示されている | 動的タイトル |

```dax
前年比表示 =
VAR 率 = [前年比]
VAR 記号 = IF( 率 >= 0, "▲", "▼" )
RETURN
    IF( ISBLANK( 率 ), "—", 記号 & " " & FORMAT( ABS( 率 ), "0.0%" ) )
```

## トラブルシューティング

| 症状 | 原因 | 対処 |
|---|---|---|
| 要件が固まらない | Q3（何を決めるか）を聞いていない | 決定を1つに絞ってもらう |
| 指標が20個になる | 依頼を全部受けた | KPIツリーで「打ち手のない指標」を落とす |
| 画面が詰まって読めない | 情報階層を決めずに配置した | ワイヤーフレームから描き直す |
| 依頼者が判断できない | しきい値がない | アラート条件を要件シートで確定する |
| 「Excelのほうが早い」と言われる | 既存の見方を無視した | Q5で見せてもらったExcelの列を再確認 |
| 使われなくなった | 意思決定のタイミングと合っていない | 更新時刻と閲覧時刻を合わせる |
| 追加依頼が止まらない | 目的が拡張し続けている | 別レポートとして切り出す |

## 発展課題

### 課題1：ダークパターンを排除する（15分）

次の3つが自分のレポートに紛れ込んでいないか点検してください。

1. **3D円グラフ**：面積が歪み、比較を誤らせる
2. **0から始まらない棒グラフ**：差が実際より大きく見える
3. **二重軸の折れ線**：相関があるように見せかけられる

いずれも「意図せず誤読させる」表現です。棒グラフのY軸は必ず0から始めてください。

### 課題2：ストーリーの順序を検証する（20分）

レポートを印刷し、ビジュアルを1つずつ紙で隠しながら「この順で読んで話が通じるか」を確認してください。左上から右下へ読んで話が飛ぶなら、配置を入れ替えます。

### 課題3：1ページに削ぎ落とす（20分）

3ページのレポートを、**1ページだけ**に再構成してください。ブックマークとドリルスルーを駆使します。「削れないもの」だけが残った状態が、そのレポートの本質です。

### 課題4：想定質問集を作る（15分）

依頼者から出そうな質問を10個書き出し、それぞれレポートのどこを見れば答えられるかを対応させてください。答えられない質問が3つ以上あれば、設計を見直します。
