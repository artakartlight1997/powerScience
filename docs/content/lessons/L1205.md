## 設計判断チェックリスト

- [ ] 本当にインポートで収まらないのか。列削減と増分更新を先に試したか
- [ ] DirectQuery のファクトにつながる次元をすべてデュアルにしたか
- [ ] 制限付きリレーションシップが発生していないか確認したか
- [ ] 集計の粒度は、実際によく使われる粒度に合っているか
- [ ] 集計テーブルとディメンションの関係を張ったか
- [ ] GroupBy 列の型が集計側と明細側で一致しているか
- [ ] 集計テーブルを利用者から非表示にしたか
- [ ] 代表的なビジュアルでヒットを実測したか
- [ ] `DISTINCTCOUNT` を使うメジャーの扱いを決めたか
- [ ] 他モデルを参照する場合、RLSの伝播を実ユーザーで検証したか
- [ ] ソースDBのインデックス設計をDBAと確認したか

## 理解度チェック
