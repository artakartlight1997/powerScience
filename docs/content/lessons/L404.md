## 計算に名前をつける

あきは「売上合計」という名前をつけることにした。

計算を書く場所を開いて、名前と中身を1行書くだけだ。

```dax
売上合計 = SUM('sales'[金額])
```

## 割り算にも、名前をつけられる

たい焼き1個あたり、平均いくらで売れているのか。

金額の合計を、個数の合計で割ればいい。

```dax
1個あたりの平均 = [売上合計] / SUM('sales'[個数])
```
