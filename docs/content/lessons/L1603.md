## 領域3・4の迷いやすい論点

| 迷う場面 | 判断 |
|---|---|
| 非表示かロックか | 見せない＝非表示、見せるが変更させない＝ロック |
| ドリルダウンかドリルスルーか | 同じビジュアル内＝ダウン、別ページへ＝スルー |
| フィルターか強調か | 他ビジュアルを絞る＝フィルター、色で示す＝強調 |
| アプリか共有か | 人数が多い・管理が要る＝アプリ |
| 共同作成者かメンバーか | アプリを発行させるならメンバー以上 |
| ゲートウェイは要るか | データが社内にあるなら要る |
| 昇格済みか認定済みか | 自己申告＝昇格済み、公式承認＝認定済み |
| RLSかOLSか | 行を隠す＝RLS、列やメジャーを隠す＝OLS |
| Pro か Premium/PPU か | 無料ユーザーへの配布・大容量・パイプラインは Premium/PPU |

## まとめ

- 領域3・4は暗記で確実に取れる。取りこぼしが最も痛い
- フィルターは範囲で覚える。非表示とロックは別物
- 相互作用は フィルター / 強調 / なし の3択
- ドリルダウンは同じビジュアル、ドリルスルーは別ページ
- アクセシビリティは 代替テキスト・タブ順序・色以外の手がかり・テーブル表示
- ワークスペース4ロール。共同作成者はアプリを発行できない
- 社内データにはゲートウェイ。Pro の更新は1日8回が目安
- 100人配布はアプリ。RLS はビューアーに効く
- パイプラインとリネージ、影響分析はガバナンスの定番機能
