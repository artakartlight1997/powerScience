会議で「先月の売上はどうでしたか」と聞かれたとします。あなたは何秒で答えられますか。そして、その数字は隣の席の人が答える数字と一致しますか。

この2つの問いに自信を持って「はい」と言える組織は多くありません。数字が出てくるまでに3日かかり、出てきた数字が部署ごとに違う。これがデータ分析を学ぶ理由のすべてです。**BI（ビジネスインテリジェンス、業務データを収集・整理・可視化して意思決定に使えるようにする一連の仕組み）**は、この状態を解消するための技術体系です。

このレッスンでは Power BI の操作を一切扱いません。しかしここを飛ばした人は、必ず「誰も見ないレポート」を作ります。道具の前に、まず何のために測るのかを固めます。

## 勘と経験は「悪」ではない

最初に誤解を解きます。データ分析は勘と経験を否定する技術ではありません。熟練者の勘は、大量の経験を圧縮した高性能な予測モデルです。ベテラン店長が「明日は雨だから弁当を2割減らす」と判断するとき、その頭の中では過去数百日の天候と売上の関係が処理されています。これは立派な分析です。

問題は、勘が効く条件が限られていることです。勘が信頼できるのは次の3つが揃ったときだけです。

```figure
{ "type": "cards", "cols": 3, "title": "勘が信頼できる3条件",
  "caption": "1つでも欠けると、経験則は静かに外れ始める",

    {"icon":"🔁","title":"繰り返しがある","text":"同じような状況を何十回も経験している。初めての事業や新商品では成立しない。","tone":"blue"},
    {"icon":"⏱","title":"フィードバックが速い","text":"判断の結果が数日以内にわかる。1年後にしか結果が出ない判断では、経験は蓄積されない。","tone":"green"},
    {"icon":"🌏","title":"環境が安定している","text":"ルールが変わらない。市場や顧客層が急変すると、過去の経験がそのまま誤りになる。","tone":"amber"} ] }
```

現代のビジネスは、この3条件がどんどん崩れる方向に動いています。商品サイクルは短くなり、販売チャネルは増え、顧客の行動は数年で変わります。だから経験を捨てるのではなく、**経験が届かない範囲をデータで補う**のです。

## 人の判断が外れる3つの仕組み

経験則が外れるとき、人は「運が悪かった」と考えます。しかし実際には、外れ方には規則性があります。認知科学が繰り返し確認してきた代表的なものを3つ押さえます。

### 確証バイアス

**確証バイアス**とは、自分の仮説を支持する情報ばかりを集め、反証する情報を軽視する傾向のことです。「若い顧客層が伸びている」と信じている人は、20代の来店が増えた話をよく覚え、40代の売上が2倍になった事実を見落とします。

### 生存者バイアス

**生存者バイアス**とは、生き残った対象だけを見て全体を判断してしまう誤りです。「解約した顧客」はデータから消えるため、残っている顧客のアンケートだけを見ると「みんな満足している」という結論になります。本当に聞くべきは、もう来ない人の理由です。

### 小さすぎる標本

「今日3人のお客様が同じことを言っていた」は強い印象を残しますが、統計的にはほとんど情報がありません。**標本（サンプル、全体から取り出した一部のデータ）**が小さいと、偶然の偏りが本物の傾向に見えてしまいます。

```figure
{ "type": "compare", "title": "同じ売上データ、2つの読み方",
  "caption": "印象は強いほうに引っ張られる。だから記録が要る",
  "panels": [
    {"title":"印象で語る","tone":"bad","items":[
      "「最近、家電が売れてない気がする」",
      "根拠は直近1週間の店頭の体感",
      "反論できないので声が大きい人の意見が通る",
      "翌月には誰も何を決めたか覚えていない"],
     "note":"再現できない"},
    {"title":"データで語る","tone":"good","items":[
      "「家電カテゴリは2年間で売上の85%を占める」",
      "根拠は6,948件の全注文明細",
      "定義と集計方法が示されるので検証できる",
      "同じ集計を来月も自動で再現できる"],
     "note":"再現できる"} ] }
```

> [!DS] 大数の法則と小標本
> サイコロを6回振って1が3回出ることは珍しくありませんが、6,000回振れば出目の割合はほぼ6分の1に収束します。これを**大数の法則**といいます。実務での教訓は単純で、**判断の重さと標本の大きさを釣り合わせる**ことです。3人の声で全社方針を決めてはいけませんが、3人の声から仮説を立てて6,000件で検証するのは正しい進め方です。

## データ分析が肩代わりする4つのこと

では、データは人間の何を補うのでしょうか。「分析」という言葉を分解すると、実際には4つの別々の仕事が入っています。

```figure
{ "type": "flow", "dir": "row", "title": "データが人間を補う4つの機能",
  "caption": "どれか1つでも欠けると、意思決定は勘に戻る",
  "items": [
    {"label":"記憶","sub":"3年前の同じ月を\n正確に思い出す","tone":"blue","icon":"🧠"},
    {"label":"網羅","sub":"6,948件を\n1件も漏らさず数える","tone":"green","icon":"🔍"},
    {"label":"比較","sub":"前年・他店舗・目標と\n同じ基準で並べる","tone":"amber","icon":"⚖"},
    {"label":"共有","sub":"全員が同じ数字を\n同じ定義で見る","tone":"violet","icon":"🤝"} ] }
```

このうち実務で最も価値が高いのは、意外にも4番目の「共有」です。営業部の言う「売上」が受注ベース、経理の言う「売上」が計上ベースだと、どれだけ精緻な分析をしても会議は数字の擦り合わせで終わります。**単一の真実（Single Source of Truth、組織全体が参照する唯一の正しいデータの置き場）**を作ることが、BI導入の最大の効果です。

## BIの4段階 — 何が起きたか、から、どうすべきか、へ

分析には深さの段階があります。この階段のどこにいるかを意識すると、次にやるべきことが明確になります。

```figure
{ "type": "stack", "title": "分析の4段階",
  "caption": "上に行くほど価値は高いが、下の段が固まっていないと上は砂上の楼閣になる",
  "layers": [
    {"label":"処方的分析 Prescriptive","sub":"どうすべきか — 在庫を何個発注すべきか","tone":"pink"},
    {"label":"予測的分析 Predictive","sub":"何が起きそうか — 来月の需要はいくつか","tone":"violet"},
    {"label":"診断的分析 Diagnostic","sub":"なぜ起きたか — どの店舗のどの商品が落ちたか","tone":"amber"},
    {"label":"記述的分析 Descriptive","sub":"何が起きたか — 先月の売上は1,875万円だった","tone":"blue"} ] }
```

Power BI が主戦場とするのは下の2段、**記述的分析と診断的分析**です。「地味だ」と感じるかもしれません。しかし実務の意思決定の大半は、この2段が速く正確に回るだけで劇的に改善します。予測モデルを作る前に、まず「先月何が起きたか」を全員が3秒で確認できる状態を作るほうが、投資対効果は桁違いに高いのです。

> [!NOTE] 順番を飛ばさない
> 記述が不正確なまま予測モデルを作ると、間違ったデータで学習した予測が出てきます。「Garbage In, Garbage Out（ゴミを入れればゴミが出る）」は分析の世界で最も古く、最も繰り返される教訓です。

## 「データドリブン」の落とし穴

**データドリブン**とは、意思決定をデータに基づいて行う姿勢のことです。ただしこの言葉は誤解されがちで、「データが判断してくれる」という意味ではありません。

```figure
{ "type": "compare", "title": "データドリブンの誤解と正解", "panels": [
    {"title":"よくある誤解","tone":"bad","items":[
      "データが結論を出してくれる",
      "数字が出れば議論は不要になる",
      "とにかく全部のデータを集める",
      "グラフが多いほど良いレポート"],
     "note":"分析疲れを起こす"},
    {"title":"実際に機能するやり方","tone":"good","items":[
      "データは選択肢を絞る。決めるのは人",
      "数字は議論の共通の土台をつくる",
```

データは「どの選択肢がどれくらい良さそうか」までしか教えません。リスクをどこまで取るか、何を優先するかは価値判断であり、人間の仕事です。**分析の目的は判断を代行することではなく、判断の質を上げること**だと覚えてください。

> [!TRAP] 分析のための分析
> 「もっとデータを集めてから決めましょう」は、決断を先送りする最も上品な方法です。判断に必要な精度は、判断の重要度で決まります。100万円の意思決定に3か月のデータ収集をかけるのは、分析ではなく回避です。**いつまでに、どの精度で、何を決めるのか**を先に書いてから分析を始めます。

## よくある反論に答える

データ分析を職場に持ち込むと、必ず次の反論に出会います。答えを用意しておきましょう。

**「うちの業界は特殊だからデータでは測れない」** — 測れないのは指標設計をしていないだけであることがほとんどです。完全に測れなくても、代わりになる数字（**代理指標**）は必ずあります。顧客満足度そのものは測りにくくても、再購入率や問い合わせ件数は測れます。

**「データを見ても現場のことはわからない」** — その通りです。だからデータは現場の観察と組み合わせて使います。データは「どこを見に行くべきか」を教えてくれる地図であり、現場はその地図の答え合わせです。順序は「数字で異常を見つけ、現場で理由を確かめる」です。

**「集計する時間がない」** — これこそ Power BI が解決する問題です。手作業の集計は毎月同じ時間を消費しますが、一度作ったレポートは更新ボタン1つで再現されます。初回に3時間かけて、翌月から毎月3時間を取り戻す投資です。

```figure
{ "type": "chart", "kind": "line", "title": "手作業集計と自動化の累積作業時間",
  "caption": "初期投資は大きいが、4か月目で逆転する。実務ではこの逆転点を先に示すと合意が得られる",
  "categories": ["1月","2月","3月","4月","5月","6月"],
  "series": [
    {"name":"手作業（毎月3時間）","values":[3,6,9,12,15,18],"tone":"bad"},
    {"name":"Power BI（初回8時間＋毎月0.5時間）","values":[8,8.5,9,9.5,10,10.5],"tone":"good"} ],
  "unit": "時間" }
```

## まとめ

- 勘は「繰り返し・速いフィードバック・安定した環境」が揃うときだけ信頼できる。現代のビジネスではこの条件が崩れやすい
- 人の判断は確証バイアス・生存者バイアス・小標本によって系統的に外れる。運ではなく仕組みで外れる
- データは記憶・網羅・比較・共有の4つを肩代わりする。中でも「共有」＝単一の真実の確立が最大の価値
- 分析には記述・診断・予測・処方の4段階があり、Power BI は下の2段を高速化する道具
- データは判断を代行しない。選択肢を絞り、議論の土台を作るのが役割
- 使われないレポートの原因は「問いがない」「信頼されていない」「読むのに時間がかかる」の3つ

1. あなたの職場の判断のうち、「勘で十分な判断」と「データで補うべき判断」をそれぞれ1つ挙げ、その理由を勘が信頼できる3条件を使って説明してください。
