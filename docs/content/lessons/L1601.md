## よくある勘違い

| 勘違い | 実際 |
|---|---|
| 「実務経験がないと受からない」 | 範囲を体系的に学べば合格できる。ただし Desktop を一度も触らずに受かるのは難しい |
| 「DAXを全部暗記する必要がある」 | 問われるのは代表的な関数の役割と使い分け。長い式を書かせる問題は出ない |
| 「Power BI Service を触らなくてよい」 | 領域4は Service の話。無料試用でよいので必ず触る |
| 「模擬試験を丸暗記すれば受かる」 | 同じ問題は出ない。言い回しのパターンを覚えるために使う（L1604） |
| 「700点＝70問中49問正解」 | スケールスコアであり、正答率とは一致しない |
| 「不合格だと記録が残って不利」 | 不合格の記録は公開されない。回数制限の範囲で再挑戦できる |
| 「Fabric の知識が必要」 | 中心は Power BI。ただしデータフローやワークスペースまわりで Fabric 由来の用語に触れる |
| 「電卓が使える」 | 使えない。計算させる問題はほぼ出ないので不要 |

## 不合格だった場合

落ちても失うものはほとんどありません。手順が決まっています。

| 回数 | 待機期間（目安） | やること |
|---|---|---|
| 1回目の不合格後 | 24時間 | スコアレポートの領域別バーを記録し、最も低い領域のレッスンへ戻る |
| 2回目以降 | 14日 | 弱点領域の演習を集中的に。同じ模擬試験の繰り返しは効果が薄い |
| 年間 | 同一試験は年5回まで | 5回目までに合格する前提で計画を立てる |

> [!NOTE] 要点
> スコアレポートは**受験後にMicrosoft Certification Dashboardからも確認できます**。領域ごとのバーは「合格者平均と比べて自分がどこにいるか」を示すため、次の学習計画の材料になります。感情的に落ち込む前に、まずこのバーを写真に撮ってください。

## まとめ

- 出題範囲は公開されている。24スキル項目を全部見てから計画を立てる
- 領域1〜3が各25〜30%、領域4が15〜20%。領域ごとの合格ラインはない
- 合格はスケールスコア700。正答率70%という意味ではない
- 複数選択に部分点はない。未回答は誤答と同じなので必ず埋める
- ケーススタディなど「戻れないセクション」がある
- 24項目を◎○×で採点し、×から潰す。領域4の×は最も効率がよい
- 数値は変わる。申込前に必ず公式ページと Study Guide を確認する
