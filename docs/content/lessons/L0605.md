```dax
Dim_日付 =
ADDCOLUMNS(
    CALENDAR( DATE(2023,1,1), DATE(2026,12,31) ),
    "年",       YEAR( [Date] ),
    "月番号",   MONTH( [Date] ),
    "月名",     FORMAT( [Date], "M" ) & "月",
```

## よくあるエラーと対処

| 症状 | 原因 | 対処 |
|---|---|---|
| 日付テーブルとしてマークできない | 重複・欠落・型の誤り | 生成範囲と型を確認。date に変換する |
| 前年同月比が空白になる | 日付テーブルが前年を含まない | 範囲を前年まで広げる |
| 売上が全部「(空白)」の月に集まる | ファクトの日付列に時刻がある | Power Query で date 型に変換する |
| モデルサイズが不自然に大きい | 自動の日付/時刻の隠しテーブル | オプションでオフにする |
| 月が「1月・10月・11月」と並ぶ | 月名が文字列で並べ替え列がない | 月番号で並べ替えを設定（L0606） |
| 年度累計が4月始まりにならない | 会計年度に対応していない | TOTALYTD の年度末引数を指定する |
| CALENDARAUTO で1900年から始まる | 無関係な日付列が範囲に入った | CALENDAR で範囲を明示する |
| 出荷日で集計すると受注日の値が出る | USERELATIONSHIP を書いていない | CALCULATE 内で明示的に切り替える |
