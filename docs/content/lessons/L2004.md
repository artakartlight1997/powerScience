## Python / R ビジュアルの制約

選択したフィールドを DataFrame として受け取り、matplotlib で描いた**静止画**を返します。

```python
import matplotlib.pyplot as plt
fig, ax = plt.subplots(figsize=(8, 5))
ax.scatter(dataset["広告費"], dataset["売上金額"], alpha=0.6)
ax.set_xlabel("広告費（千円）")
ax.set_ylabel("売上金額（千円）")

plt.show()
```

| 制約 | 内容 | 実務上の意味 |
|---|---|---|
| 行数の上限 | 概ね15万行まで | 明細をそのまま渡さず事前に集計する |
| 重複行の除去 | 渡される DataFrame は重複行が削除される | 一意キーを1列含めないと分布が変わる |
| 実行時間の上限 | 一定時間で打ち切られる | 学習処理をビジュアル内で行わない |
| 出力は画像 | ツールチップ・ドリル・書式が効かない | 対話が必要ならネイティブビジュアル |
| ライブラリ制限 | Service は許可パッケージのみ | 特殊なライブラリ依存を避ける |
| 公開の制限 | 一部の公開・埋め込みで表示されない | 社外配布前に必ず表示確認する |
