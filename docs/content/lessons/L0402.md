実務のデータは1か所にありません。売上は基幹システムのデータベース、予算はExcel、為替レートはWeb、店舗マスタはCSV。これらを1つのレポートにまとめるのが Power BI の役割です。

Power BI は100種類以上のコネクタを持ちますが、覚えるべきは**ソースの種類ごとの落とし穴**です。ここを知らずに繋ぐと、初回は動いても翌月に壊れます。

### クエリフォールディング

**クエリフォールディング**とは、Power Queryで行った操作が可能な限りソース側のSQLに翻訳され、ソース側で実行される仕組みです。

```figure

  "nodes": [
    {"id":"pq","label":"Power Query\n「2025年だけ」\n「3列だけ」","tone":"green"},

    {"from":"pq","to":"sql","label":"変換"},
    {"from":"sql","to":"db","label":"送信"},
    {"from":"db","to":"pbi","label":"結果のみ返す"} ] }
```

フォールディングが効いているかは、Power Queryエディタで**ステップを右クリック →「ネイティブクエリの表示」**が有効かどうかで確認できます。有効ならフォールディングされています。L0405で再度扱います。

> [!DS] 処理をどこでやるか — 押し下げの原則
> データ処理の世界には**「計算はデータのある場所で行う」**という原則があります。1億行を手元に持ってきてから10行に絞るのは、ネットワークもメモリも無駄です。データベース側で10行に絞ってから受け取れば、同じ結果を桁違いの速さで得られます。これはSQLの実行計画でも、分散処理でも、BIツールでも共通する基本原則です。Power Queryのフォールディングは、この原則を自動でやってくれる仕組みだと理解してください。**ソース側でできることをソース側にやらせる。** 性能改善の第一歩は常にここです。

## プライバシーレベル

複数のソースを組み合わせるとき、Power BI は**プライバシーレベル**を確認します。これは「あるソースのデータを、別のソースに送ってよいか」を制御する仕組みです。

| レベル | 意味 |
|---|---|
| プライベート | 他のソースへ一切データを渡さない。最も厳格 |
| 組織 | 組織内の他ソースとは組み合わせ可能 |
| パブリック | 制限なし |

> [!WARN] プライバシーレベルが性能を落とすことがある
> レベルが厳格だと、フォールディングが無効になり、両方のデータをすべて手元に読み込んでから結合することになります。これが「なぜか異常に遅い」原因になっている場合があります。ただし**設定を緩めることは、社内の顧客データを外部APIに送信する可能性を開く**ことを意味します。性能のために安易に無効化せず、内容を理解して判断してください。

> 取り込んだクエリの名前は既定でファイル名になります。`sales`、`products` のように短く統一しておくと、後のDAX記述が読みやすくなります。日本語名でも動きますが、**表記ゆれ（全角半角・スペース）が事故の原因**になるため、英数字の短い名前を推奨します。名前の変更はPower Queryエディタ左側のクエリ一覧から行います。

## まとめ

- Excelは必ず**テーブル（Ctrl+T）**として読み込む。シート指定は行の増減で壊れる
- フォルダー接続で、毎月増えるファイルを自動的に一括取り込みできる。列構成の固定が前提
- Web接続は便利だが最も壊れやすい。公式APIやファイル配信があればそちらを使う
- データベースはナビゲーターでテーブル/ビューを選ぶ。**SQL直書きはフォールディングを止める**
- クエリフォールディングは、変換をソース側のSQLに翻訳して実行させる仕組み。性能の鍵
- 「計算はデータのある場所で行う」が処理設計の基本原則
- 認証はデータソース設定から確認・削除できる。詰まったらまずここを見る
- プライバシーレベルは安全のための仕組み。性能のために安易に無効化しない

## 理解度チェック（自分に説明してみる）

1. 毎月1本ずつ増えるCSVが36本あるフォルダを取り込みます。どう接続し、翌月以降の運用がどうなるかを説明してください。
2. データベース接続で「SQL文を直書きしない」ほうがよい理由を、クエリフォールディングの観点から説明してください。例外的に直書きしてよいのはどんな場合ですか。
3. 同じ売上データが「基幹DB」「毎月出力されるCSV」「担当者が手作業で作るExcel」の3か所にあります。どれを選び、なぜそう判断しますか。
