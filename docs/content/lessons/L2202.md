KPIが30個並んだ経営会議で、決まることは何もありません。指標の多さは優先順位の放棄です。

やるべきは指標を集めることではなく、**事業を数式に分解し、動かせる変数を特定する**ことです。

> [!NOTE] 要点
> 分解に使う演算は掛け算と足し算の2つだけ。ツリーの葉は必ず誰かの行動につながる。

```dax
-- ベースメジャー（最小単位）
売上金額 = SUM( Fact_売上[売上金額] )
客数     = DISTINCTCOUNT( Fact_売上[会員ID] )

-- 分解メジャー（ツリーの構造をそのまま式にする）
客単価   = DIVIDE( [売上金額], [客数] )
買上点数 = DIVIDE( SUM( Fact_売上[数量] ), [レシート枚数] )
平均単価 = DIVIDE( [売上金額], SUM( Fact_売上[数量] ) )

-- 目標テーブルとの比較
売上目標   = SUM( Fact_目標[目標金額] )
売上達成率 = DIVIDE( [売上金額], [売上目標] )

-- 寄与度分解：売上の前年差を客数要因と単価要因に分ける
客数寄与 = ( [客数] - [客数_前年] ) * [客単価_前年]
単価寄与 = ( [客単価] - [客単価_前年] ) * [客数]
```

KPI設計は技術ではなく**合意形成**の仕事です。数式そのものは中学生でも書けます。

## 理解度チェック

1. 「売上を10%伸ばす」をKPIツリーで具体的な行動計画に落とす手順を説明してください。
2. 平均通話時間の短縮をKPIにしたら満足度が下がった。現象名と修正案を述べてください。
3. 部署ごとに「売上」の定義が違う。統一以外の方法で取るべき対応を説明してください。
