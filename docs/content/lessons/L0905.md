表は情報密度が最も高いビジュアルです。1画面に数百の数値を載せられます。

密度を落とさず読みやすくする道具が、条件付き書式・ツールチップ・スモールマルチプルです。

> [!NOTE] 要点
> 表の中でも知覚精度は同じ。データバー ＞ アイコン ＞ 背景色。順位は色で読ませない。

書式スタイルの**フィールド値**を使うと、DAXが返した色コードをそのまま適用できます。

```text
色_要対応 =
VAR 前年比 = DIVIDE([売上合計], [売上合計_前年])
VAR 規模大 = [売上合計] >= 100
RETURN
    IF( 前年比 < 0.9 && 規模大, "#C0492F", "#1F2933" )
```

## 理解度チェック

1. 「どの店舗が大きいか」を素早く読ませたい。背景色とデータバーのどちらを選ぶか。
2. ツールチップページの補足指標がスマホで見えないと言われた。原因と対処を述べよ。
3. スモールマルチプルで規模の差が分からない。考えられる設定と対処を述べよ。

<details>
<summary>解答の要点</summary>

1. データバー。共通基線からの長さで知覚精度が高い。背景色の濃淡は最下位で順位読み取りに不向き。
2. ツールチップはモバイル表示とPDF書き出しに含まれない。判断に必要な指標は画面本体へ移す。
3. 各パネルのY軸が個別スケールになっている。書式ペインで共通スケール（既定）に戻す。

</details>
