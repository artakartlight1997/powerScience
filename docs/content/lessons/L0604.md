| 該当行があり合計が0 | 0 | 取引はあったが金額が0だった |

## 理解度チェック

1. Dim_商品 で「家電」を選ぶと Dim_店舗 の行は絞られますか。その仕様が実務上ありがたい理由も述べてください。
2. 店舗別顧客数の各行を足しても総計と一致しません。何が起きていて、どちらが正しいですか。
3. 双方向にしたらリレーションシップが非アクティブになりました。原因と直し方を説明してください。

## よくあるエラーと対処

| 症状 | 原因 | 対処 |
|---|---|---|
| スライサーが特定のビジュアルに効かない | 経路がない、または向きが逆 | 経路と矢印を確認。相互作用の設定も見る |
| 総計が各行の合計と一致しない | 比率や重複排除は再計算される | 仕様。レポートに注釈を入れる |
| リレーションシップが非アクティブになった | 双方向で経路があいまい | 双方向を単一に戻す |
| 売上0の組み合わせが表示されない | メジャーが空白を返している | 必要なら `+0`。行数の爆発に注意 |
| RLSで見えてはいけない行が見える | 双方向で行フィルターが波及した | 双方向を外し単一方向で設計する |
| 双方向にしたら急に遅くなった | 実行計画が最適化されない | 単一方向に戻し CROSSFILTER で局所化 |
