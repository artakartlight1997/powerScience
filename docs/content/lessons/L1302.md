> CALCULATE が実行されると、その時点の行コンテキストが同じ値のフィルターコンテキストに変わる。

## 遷移が打ち消されるとき

```dax
-- 遷移で顧客が絞られるが、内側の ALL がそれを打ち消す
消える遷移 =
SUMX(
    VALUES( Dim_顧客[CustomerID] ),
    CALCULATE( [売上合計], ALL( Dim_顧客 ) )
)
```

## 理解度チェック

**問1.** `Dim_商品` の計算列 `= SUM( Fact_売上[SalesAmount] )` が全行同じ値になる理由と直し方は。

<details>
<summary>解答</summary>

行コンテキストは集計関数のフィルターにならないためです。`CALCULATE( SUM(…) )` と包めば遷移が起き、商品ごとの売上になります。
</details>

**問2.** `SUMX( VALUES( Dim_店舗[StoreID] ), [売上合計] )` と、第2引数を `SUM( Fact_売上[SalesAmount] )` にした式の違いは。

<details>
<summary>解答</summary>

前者は遷移が起きて店舗ごとの売上を合計するので総売上と一致します。後者は遷移がなく「店舗数 × 総売上」になります。
</details>

**問3.** イテレータ内の `CALCULATE( [売上合計], ALL( Dim_顧客 ) )` で遷移の効果が消える理由は。

<details>
<summary>解答</summary>

CALCULATE は遷移 → フィルター引数 → 式評価の順で処理します。後から適用される `ALL` が、遷移が置いた顧客フィルターを解除するためです。
</details>
