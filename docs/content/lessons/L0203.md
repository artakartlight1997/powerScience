Power BI を学び始めた人がよく口にするのが「Excelはもう使わないほうがいいですか」という質問です。答えははっきりしています。**使い続けてください。** ただし、役割を分けてください。

Excel と Power BI は競合製品ではなく、設計思想がまったく違う道具です。違いを構造から理解すれば、どちらを使うべきかは自動的に決まります。

## 機能の比較

| 観点 | Excel | Power BI |
|---|---|---|
| 得意なデータ量 | 数万行まで（上限1,048,576行） | 数百万〜数千万行（圧縮して保持） |
| 更新の手間 | 毎回手作業で貼り替え | 更新ボタン1回または自動スケジュール |
| 手順の記録 | 人の頭の中（またはマクロ） | 適用したステップとして自動記録 |
| 複数表の結合 | VLOOKUP / XLOOKUPで1表に統合 | リレーションシップで繋いだまま扱う |
| 計算の定義場所 | セルごとに散在 | メジャーとして1か所に定義 |
| 共有 | ファイルをメール添付（版が乱立） | URLで最新版を全員が見る |
| 権限管理 | ファイル単位・パスワード | 行レベルまで制御可能 |
| 自由記入・What-if | 非常に得意 | 苦手（パラメータ機能で限定的に可能） |
| 学習コスト | 低い（誰でも触れる） | 中〜高（モデリングの理解が要る） |

> [!NOTE] 決定的な差は「再現性」
> Power BI の最大の価値は、グラフの美しさでもデータ量でもなく、**同じ手順が何度でも自動で再現されること**です。毎月3時間かかっていた集計が更新ボタン1回になる。この差は時間の節約以上に、**人が変わっても同じ数字が出る**という組織的な価値を生みます。

## VLOOKUPとリレーションシップ

Excel経験者が最も強く変えるべき習慣が、**「1枚の表にまとめようとする」**発想です。

```figure

  "before": {"title":"Excelの発想：VLOOKUPで1枚に統合","tone":"bad",
    "head":["OrderID","ProductID","商品名","カテゴリ","単価","数量","金額"],
    "rows":[
      ["O000001","P0027","!ノートPC","!家電","!128000","1","128000"],
      ["O000002","P0027","!ノートPC","!家電","!128000","2","256000"],
      ["O000003","P0027","!ノートPC","!家電","!128000","1","128000"]]},
  "after": {"title":"Power BIの発想：2表のまま関係で繋ぐ","tone":"good",
    "head":["表","中身"],
    "rows":[
      ["売上表","OrderID / ProductID / 数量 / 金額（6,948行）"],
```

VLOOKUPで統合すると、「ノートPC」「家電」「128000」という同じ文字列が6,948行分すべてに複製されます。商品名が変わったら全行を直す必要があります。一方リレーションシップなら、商品表の1行を直すだけで全体に反映されます。


> [!DS] 正規化という考え方
> 同じ情報を複数の場所に持たない設計を**正規化**といいます。データベース設計の基本原則で、目的は「更新の異常」を防ぐことです。商品名を1か所でしか持たなければ、修正漏れによる不整合が起こりません。ただしBIの世界では、**分析性能のために意図的に一部を非正規化する**（スタースキーマ）という選択もします。「正規化が常に正しい」わけではなく、**更新の一貫性を守りたいなら正規化、集計を速くしたいなら適度な非正規化**という使い分けです。ティア2で詳しく扱います。

> 組織で最も高くつくのは、計算時間ではなく**数字の不一致を調べる時間**です。営業部と経理部が違う売上を出し、会議の半分が突き合わせに費やされる。この損失は、Excelの遅さより桁違いに大きいコストです。BIの導入目的をひとことで言えば、「全員が同じ数字を、同じ定義で、同じタイミングで見る状態」を作ることです。これを**単一の真実**と呼びます。ツールの機能比較より、この状態を作れるかどうかで判断してください。

## まとめ

- Excelはセル指向で自由、Power BIはテーブル指向で厳格。この設計思想の差がすべての機能差を生む
- Power BI の最大の価値は再現性。同じ手順が自動で何度でも実行される
- 移行のサインは「毎月同じ作業」「重い・壊れる」「版の乱立」「複数ファイルの突き合わせ」
- 入力・What-if・その場限りの集計はExcelが速い。無理に移さない
- VLOOKUPで1枚にまとめず、表を分けたままリレーションシップで繋ぐ
- ピボットテーブルの「値」がメジャーに相当する。違いは再利用できるかどうか
- 見た目のためのExcel加工（セル結合・多段ヘッダー・色フラグ）は読み込めない。整然データにする
- 「Excelで分析」機能を使えば、定義はPower BI、深掘りはExcelという併用ができる
