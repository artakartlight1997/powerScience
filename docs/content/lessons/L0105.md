「売上のデータがあるので、とりあえずグラフにしてください」。この依頼に対して手が止まる人は正常です。グラフは「データの絵」ではなく、**問いに対する答えの形**だからです。

ビジネスで発生する問いは、実はほとんどが5つの型のどれかに分類できます。型が決まればグラフは自動的に決まります。逆に言えば、グラフ選びに迷うのは問いが定まっていないサインです。

## 型1：比較 — どれが大きいか

最も多い型です。カテゴリ間の大小を見ます。

```figure
{ "type": "chart", "kind": "hbar", "title": "地域別売上（2024-2025年 合計）",
  "caption": "横棒＋降順ソート。これが比較の基本形",
  "categories": ["関東","近畿","オンライン","中部","九州","北海道","中国","東北"],
  "series": [{"name":"売上","values":[94.1,54.7,42.0,33.9,20.7,12.6,11.0,6.9],"tone":"blue"}],
  "highlight": 0, "unit": "百万円" }
```

比較で守るべきルールは3つです。

- **降順（または昇順）にソートする。** カテゴリ名の五十音順に並べるのは、順位を読ませない見せ方です
- **項目が7つを超えたら横棒にする。** 縦棒はラベルが斜めになって読めなくなります
- **軸は必ず0から始める。** 棒の長さが値の比率を表すためです

> [!TRAP] 比較には「同じ土俵」が要る
> 「関東が1位」という結論は、関東に店舗が何店あるかを見ないと意味を持ちません。規模の違うものを絶対値で比較すると、大きいものが常に勝ちます。**1店舗あたり・1人あたり・1日あたりに正規化した指標**を隣に並べるのが実務の作法です。L0102で扱った「絶対値と率はセット」がここでも効きます。

## 型2：推移 — どう変わったか

時間軸の変化を見ます。ビジネスで最も意思決定に近い型です。

```figure
{ "type": "chart", "kind": "line", "title": "月別売上の推移（2024年1月〜2025年12月）",
  "caption": "2年並べると、12月に山が来る季節性が見える",
  "categories": ["24/01","24/04","24/07","24/10","25/01","25/04","25/07","25/10","25/12"],
  "series": [{"name":"売上","values":[9.8,10.7,11.6,10.1,10.9,11.5,12.8,10.5,18.8],"tone":"green"}],
  "unit": "百万円" }
```

推移で必ず考えるのは**季節性**です。12月が高いのは施策の成果か、毎年そうなのか。判断するには次の3つの見せ方があります。

```figure
{ "type": "cards", "cols": 3, "title": "季節性を扱う3つの方法",
  "items": [
    {"icon":"📅","title":"前年同月比","text":"同じ月同士で比べる。最も簡単で最も使われる。ただし前年が異常値だと誤解を生む","tone":"blue"},
    {"icon":"〰","title":"移動平均","text":"12か月移動平均で季節変動を打ち消し、トレンドだけを見る","tone":"green"},
    {"icon":"🔀","title":"年ごとに線を重ねる","text":"横軸を1〜12月にして年別に複数線。季節パターンの違いが一目でわかる","tone":"amber"} ] }
```

> [!DS] トレンド・季節・ノイズ
> 時系列データは「トレンド（長期の方向）」「季節変動（周期的な波）」「不規則変動（ノイズ）」の3成分の重ね合わせと考えます。月次の売上が前月比で下がっても、それがノイズの範囲内なら手を打つ必要はありません。**どこまでが通常のばらつきか**を知るには、過去の月次変動幅（標準偏差）を見ます。管理図という手法では「平均±2標準偏差」を超えたら異常と判断します。何でも反応する組織は、ノイズに振り回されて疲弊します。

> [!WARN] 期間の途中で切らない
> 月次グラフの最後に「今月（まだ10日しか経っていない）」を含めると、必ず急落したように見えます。**進行中の期間は除外するか、点線・薄色で区別する。** 実務で最も多い「グラフが誤解を招いた」事故の原因がこれです。

## 型4：分布 — どう散らばっているか

L0104で扱った内容がそのまま型になります。代表値だけでは見えない偏りを見ます。

```figure
{ "type": "chart", "kind": "bar", "title": "注文金額の分布",
  "caption": "この形を見て初めて「平均39,728円」の意味が判断できる",
  "categories": ["〜5千","5千〜1万","1万〜2万","2万〜5万","5万〜10万","10万〜20万","20万〜","50万〜"],
  "series": [{"name":"件数","values":[2594,1147,1065,830,508,435,323,46],"tone":"violet"}],
  "unit": "件" }
```

分布を見る型は、実務のレポートで最も省略されがちです。しかし次のような問いには分布でしか答えられません。

- 「顧客のうち、月10万円以上使う層は何%か」
- 「配送リードタイムの9割は何日以内に収まっているか」
- 「不良率が上がったのは、全体が悪化したのか一部のロットだけか」

> [!TIP] 分布は「しきい値」の議論を生む
> 分布を見せると、会議は自然に「どこで線を引くか」という議論になります。これは非常に生産的です。平均を見せた会議は「平均を上げよう」で終わりますが、分布を見せた会議は「下位20%に何が起きているか」という具体的な問いに進みます。

## 型5：関係 — 連動しているか

2つの数値の関係を見ます。散布図が基本形です。

```figure
{ "type": "chart", "kind": "scatter", "title": "値引き率と数量の関係（イメージ）",
  "caption": "点が右上がりに並べば正の相関。ただし相関＝因果ではない",
  "categories": ["0%","5%","10%","15%","20%","25%"],
  "series": [{"name":"平均購入数量","values":[1.2,1.4,1.5,1.9,2.1,2.6],"tone":"pink"}],
  "unit": "個" }
```

**相関**とは、2つの数値が一緒に動く傾向のことです。相関の強さは-1から+1の**相関係数**で表します。+1に近いほど「片方が増えるともう片方も増える」、-1に近いほど逆方向、0付近なら無関係です。

```figure
{ "type": "cards", "cols": 4, "title": "相関を見るときの4つの注意",
  "items": [
    {"icon":"⛓","title":"相関≠因果","text":"「アイスの売上と水難事故は相関する」。原因はどちらも気温。これが疑似相関","tone":"bad"},
    {"icon":"🎯","title":"外れ値1点で変わる","text":"極端な点が1つあるだけで相関係数は大きく動く。必ず散布図で目視する","tone":"amber"},
    {"icon":"〽","title":"直線以外は測れない","text":"相関係数は直線関係しか捉えない。U字型の関係は相関0と出る","tone":"blue"},
    {"icon":"🧩","title":"層別すると消える","text":"シンプソンのパラドックスと同じ。層に分けると相関が逆転することがある","tone":"violet"} ] }
```

> [!DS] 疑似相関を見抜く3つの質問
> 相関を見つけたら、因果を主張する前に必ずこの3つを自問します。第一に**逆向きの因果はないか**（売上が高いから広告費を増やしているのでは？）。第二に**第三の変数がないか**（両方とも季節や景気で動いているのでは？）。第三に**偶然ではないか**（十分な件数があるか。100個の指標を総当たりで相関を取れば、無関係でも数個は「相関あり」に見えます）。因果を確かめる唯一確実な方法は、条件を揃えた**A/Bテスト**です。BIレポートで見えるのは相関までであり、そこから先は実験の領域だと切り分けてください。

## 型は組み合わせる

実務のレポートは、複数の型を1画面に配置します。定番の組み合わせがあります。

```figure
{ "type": "flow", "dir": "row", "title": "レポート1画面の定番構成",
  "caption": "左上から右下へ、粗い→細かいの順に配置する",
  "items": [
    {"label":"KPIカード","sub":"結論の数字\n前年比つき","tone":"blue"},
    {"label":"推移","sub":"折れ線で\n流れを示す","tone":"green"},
    {"label":"比較","sub":"横棒で\n内訳の順位","tone":"amber"},
    {"label":"明細","sub":"テーブルで\n根拠を確認","tone":"gray"} ] }
```

この「カード → 推移 → 比較 → 明細」の並びは、読み手の思考順序（結論 → 流れ → 原因 → 根拠）と一致しています。M03で実際にこの構成のレポートを作ります。

> [!NOTE] 1画面に1メッセージ
> 1つの画面で伝えるメッセージは1つに絞ります。「売上は好調だが、家電に偏っている」がメッセージなら、そのために必要なグラフは3枚で足ります。10枚並んだ画面は、読み手に「自分で探せ」と言っているのと同じです。

## まとめ

- ビジネスの問いは**比較・推移・構成・分布・関係**の5つの型に分類できる。型が決まればグラフは決まる
- 比較は降順ソートした横棒。項目が多いとき、絶対値と正規化した値をセットで見せる
- 推移は折れ線。季節性を前年同月比・移動平均・年別重ねのいずれかで扱う。進行中の期間は区別する
- 構成は円グラフより積み上げ横棒。構成「比の変化」を見るのが本来の目的
- 分布は最も省略されるが、しきい値の議論を生む最も生産的な型
- 関係は散布図。相関は因果ではない。逆向き・第三の変数・偶然の3点を必ず疑う
- 実務のレポートは「カード → 推移 → 比較 → 明細」の順に配置すると読み手の思考と一致する

## 理解度チェック（自分に説明してみる）

1. 「先月の売上が落ちた原因を知りたい」という依頼を受けました。この問いを5つの型に分解すると、どんなグラフを何枚作りますか。順番も含めて説明してください。
2. 「広告費を増やした月は売上が高い」という散布図を見せられました。ここから「広告を増やせば売上が上がる」と結論してよいか、疑似相関の3つの質問を使って検討してください。
3. カテゴリ別の売上構成比を、経営会議で報告します。円グラフを使わないとしたら何を使い、その理由をどう説明しますか。
