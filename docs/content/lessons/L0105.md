「とりあえずグラフにして」と言われて手が止まるのは正常です。

グラフはデータの絵ではなく、**問いに対する答えの形**。型が決まればグラフは自動的に決まります。

## 型1：比較 — どれが大きいか

```figure
{ "type": "chart", "kind": "hbar", "title": "地域別売上（2024-2025年 合計）",
  "caption": "横棒＋降順ソート。これが比較の基本形",
  "categories": ["関東","近畿","オンライン","中部","九州","北海道","中国","東北"],
  "series": [{"name":"売上","values":[94.1,54.7,42.0,33.9,20.7,12.6,11.0,6.9],"tone":"blue"}],
  "highlight": 0, "unit": "百万円" }
```

- 降順にソートする。五十音順は順位を読ませない見せ方
- 項目が7つを超えたら横棒。縦棒はラベルが斜めになる
- 軸は0から。棒の長さが値の比率を表すため
- 規模が違うものは1店舗あたりに正規化して隣に並べる

## まとめ

- 問いは比較・推移・構成・分布・関係の5型。型が決まればグラフも決まる
- 比較は降順の横棒。絶対値と正規化した値をセットで見せる
- 推移は折れ線。季節性は前年同月比・移動平均・年別重ねで扱う
- 構成は円より積み上げ横棒。見るべきは「構成比の変化」
- 分布は最も省略されるが、しきい値の議論を生む生産的な型
- 関係は散布図。逆向き・第三の変数・偶然の3点を必ず疑う
- 1画面は「カード→推移→比較→明細」。メッセージは1つに絞る

## 理解度チェック

1. 「先月の売上が落ちた原因を知りたい」を5型に分解し、作る順にグラフを挙げてください。
2. 「広告費を増やした月は売上が高い」から因果を言えるか、3つの質問で検討してください。
3. 経営会議で構成比を報告します。円グラフを使わないなら何を使い、どう説明しますか。
