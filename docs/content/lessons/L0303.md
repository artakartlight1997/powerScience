読み込み自体は3クリックで終わります。しかし**この工程で確認すべきことが3つ**あり、それを飛ばすと後の全工程が壊れます。文字コード・区切り記号・データ型。この3点を毎回確認する習慣をここで作ります。

### 文字コード — 文字化けの正体

```figure
{ "type": "tablediff", "arrowLabel": "ファイルの原点を UTF-8 に変更",
  "before": {"title":"文字コードが合っていない","tone":"bad",

    "rows":[
      ["P0001","!????PC ????????","!??"],
      ["P0002","!繝弱??繝?PC","!螳ｶ髮ｻ"]]},
  "after": {"title":"正しく読めている","tone":"good",
    "head":["ProductID","ProductName","Category"],
    "rows":[
      ["P0001","ノートPC スタンダード","家電"],
      ["P0002","ノートPC ハイエンド","家電"]]} }
```

このカリキュラムのCSVはすべて **UTF-8** です。一方、日本の業務システムから出力されるCSVは **Shift-JIS（932: 日本語）** であることが多く、ここが最初の関門になります。文字化けしたら慌てず、ファイルの原点を切り替えて再確認してください。

> [!TRAP] BOM付きUTF-8の1列目
> UTF-8のCSVには、先頭に**BOM**（バイト順マーク）という見えない文字が付いている場合があります。これが付いていると、1列目の列名が `OrderID` ではなく見えない文字を含んだ名前になり、後の参照が壊れます。「65001: Unicode (UTF-8)」を選ぶと正しく処理されます。列名の頭に空白のような何かがあると感じたら、これを疑ってください。

### 区切り記号 — 値の中のコンマ

CSVは「コンマ区切り」ですが、値そのものにコンマが含まれることがあります（例：住所や商品名）。この場合、値は `"東京都渋谷区, 1-2-3"` のようにダブルクォートで囲まれています。Power BI はこれを正しく解釈しますが、**元ファイルの作りが悪いと列がずれます。**

## 更新のしくみ

一度取り込んだデータは、**「ホーム → 更新」**で最新の状態に取り直せます。このとき、Power Queryに記録された手順がすべて再実行されます。

```figure
{ "type": "pipeline", "title": "更新ボタンを押したときに起きること",
  "nodes": [
    {"id":"f","label":"sales.csv\n（元ファイル）","tone":"gray"},
    {"id":"q","label":"Power Query\n記録された手順を再実行","tone":"green"},
    {"id":"m","label":"モデル\nデータを差し替え","tone":"amber"},
    {"id":"v","label":"ビジュアル\n自動で再計算","tone":"violet"} ],
  "edges": [
    {"from":"f","to":"q","label":"再読み込み"},
    {"from":"q","to":"m","label":"型変換・整形"},
    {"from":"m","to":"v","label":"再描画"} ] }
```

**列名が変わると壊れます。** 元ファイルの `SalesAmount` を `売上金額` に変えると、その列を参照していた手順がすべてエラーになります。元ファイルの列名を勝手に変えないこと、変える場合は手順側も直すことをチームのルールにしてください。

## まとめ

- 取り込み時に確認する3点は**文字コード・区切り記号・データ型検出**
- 日本語CSVは UTF-8 か Shift-JIS。文字化けは「ファイルの原点」で切り替える
- 型検出の既定は「最初の200行」。全体を見ていないため誤判定が起きる。実務では「検出しない」＋手動指定が安全
- 「読み込み」ではなく**「データの変換」**を押す。中身を見てから取り込む習慣が品質を守る
- 取り込み後は必ず検算する。行数6,948・合計276,029,967・期間2024-01-01〜2025-12-31
- ローカルの絶対パスは共有できない。発行して自動更新するならクラウド上のパスにする
- 更新ボタンは記録された手順を再実行する。元ファイルの列名を変えると壊れる
- Excelはシートではなく**テーブル**として読み込む

## 理解度チェック（自分に説明してみる）

1. CSVの取り込み時に確認すべき3点を挙げ、それぞれ確認を怠るとどんな症状が出るか説明してください。
2. 「取り込んだら合計が元ファイルより少なかった」。考えられる原因を3つ挙げ、確認する順序を説明してください。
3. 型検出を「最初の200行」のままにしておくと、どんなデータでどんな問題が起きますか。具体例を挙げて説明してください。
