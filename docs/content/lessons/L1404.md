## DAX Studio でメジャーを書き換えて試す

モデルを変更せずに、書き換え案を試す方法があります。`DEFINE MEASURE` を使います。

```dax
DEFINE
    MEASURE Fact_売上[顧客あたり平均_改] =
        AVERAGEX( VALUES( Dim_顧客[CustomerID] ), [売上合計] )

EVALUATE
    SUMMARIZECOLUMNS(
        Dim_商品[Category],
        "平均", [顧客あたり平均_改]
    )
```

`DEFINE MEASURE` で定義したメジャーは、そのクエリの中だけで有効です。**モデルには一切影響しません。**

## 計測用のクエリを自分で書く

ビジュアルのクエリは複雑で、どこが遅いのか切り分けにくいことがあります。その場合は、最小のクエリを自分で書きます。

```dax
-- 最小構成：メジャー単体の評価コストを測る
EVALUATE
    ROW( "結果", [顧客あたり平均] )
```

```dax
-- 粒度を変えて、どこから遅くなるかを探る
EVALUATE
    SUMMARIZECOLUMNS( Dim_商品[Category], "値", [顧客あたり平均] )

EVALUATE
    SUMMARIZECOLUMNS( Dim_商品[ProductName], "値", [顧客あたり平均] )

EVALUATE
    SUMMARIZECOLUMNS( Dim_顧客[CustomerID], "値", [顧客あたり平均] )
```

> [!NOTE] 要点

## 再現性のある計測をする

```figure
{ "type":"cards", "cols":3, "title":"計測の再現性を保つ3つのルール",
  "items":[
    {"icon":"🧊","title":"必ず Clear Cache する","text":"毎回コールドキャッシュから測る。これを守らないと比較が成立しない","tone":"good"},
    {"icon":"🔁","title":"3回測って中央値を取る","text":"1回の測定は環境ノイズを含む。3回測り、極端な値を捨てる","tone":"blue"},
    {"icon":"🚫","title":"他のアプリを閉じる","text":"CPUとメモリを奪い合うと測定値がぶれる。特に大きなExcelやブラウザ","tone":"amber"} ] }
```

> [!DS] データサイエンス視点
> これは**ベンチマークの基本作法**そのものです。単一測定値は分布からの1標本にすぎず、システムノイズを含みます。中央値を使うのは、外れ値（他プロセスによる一時的なCPU占有など）に対して頑健だからです。平均値だと1回の大きな外れ値に引きずられます。また、改善前後を**同じセッション・同じ条件**で測るのは、交絡要因を排除するためです。「昨日測った値と今日測った値」を比べてはいけません。

<details>
<summary>解答</summary>

**ビジュアルの描画側**です。モデルからのデータ取得は120msで完了しており、DAXやモデルの問題ではありません。データポイント数が多すぎる（散布図で数万点、テーブルで数千行など）、カスタムビジュアルが重い、条件付き書式が大量に設定されている、といった原因が考えられます。表示件数を制限するか、ビジュアルの種類を見直します。
</details>

**問2.** メジャーを書き換えて、DAX Studio で2回目の実行が10msになりました。改善できたと判断してよいですか。

<details>
<summary>解答</summary>

**判断できません。** 2回目の実行は SE キャッシュがヒットしている可能性が高いためです。「Clear Cache then Run」でコールドキャッシュから測り直し、さらに3回測って中央値を取ってから判断します。改善前も同じ条件で測り直す必要があります。
</details>

**問3.** Server Timings で SE 46ms、SE CPU 340ms と表示されました。この関係は正常ですか。

<details>
<summary>解答</summary>

**正常です。** SE CPU は全スレッドのCPU時間の合計なので、並列実行されていれば実時間の SE より大きくなります。340 ÷ 46 ≒ 7.4 なので、およそ7〜8スレッドで並列処理されたと読めます。むしろ SE CPU と SE がほぼ同じ値なら、並列化が効いていないことを疑います。
</details>
