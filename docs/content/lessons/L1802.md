**TMDL**（Tabular Model Definition Language）はモデル定義を人が読める形で書く言語。テーブル1つが1ファイルです。

```text
table Fact_売上
	measure 売上金額 = SUM ( Fact_売上[金額] )
		formatString: #,##0
		description: 値引後・返品控除後の売上。社内取引を除く。
	column 金額
		dataType: int64
		isHidden: true
```

## 理解度チェック

1. PBIXでマージできずPBIPでできる理由を、ファイル構造の違いから説明してください。
2. PR の TMDL 差分でメジャーの式が変わっていました。承認前に確認すべきことは何ですか。
3. 競合をテキストエディタで解決した後、Desktopで開いて確認すべき理由を述べてください。

## よくあるエラーと対処

| 症状 | 原因 | 対処 |
|---|---|---|
| 同じアイテムで競合が頻発する | 編集の入り口が複数ある | Desktop / ワークスペースのどちらかに固定 |
| ブランチ切替で他人の作業が消える | 開発ワークスペースを共有している | 開発者ごとのワークスペースに分ける |
| マージ後にモデルが開けない | 構文は正しいが参照が壊れている | Desktopで開き直して保存・検証 |
| レビューが形骸化する | 1PRの変更が大きすぎる | 1PR＝1目的に分割する |
| 一括変更を戻せない | ブランチを切らずに実行した | 作業前にブランチを切る |
