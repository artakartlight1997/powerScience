## 理解度チェック

1. 月名が「10月・11月・1月」と並びます。原因と対処、その機能の制約を述べてください。
2. ファクトの `ProductID` を非表示にすべき理由と、DAXから参照できる事実が意味する注意を説明してください。
3. 「売上」の定義が部署ごとに違う問題を、セマンティックモデルはどう解決しますか。作り手は何をすべきですか。

## よくあるエラーと対処

| 症状 | 原因 | 対処 |
|---|---|---|
| 月が文字コード順に並ぶ | 並べ替え列が未設定 | 列で並べ替えに月番号を指定する |
| 「複数の値が含まれています」 | 並べ替え列が1対1でない | 粒度の合う番号列を作り直す |
| 循環依存のエラーが出る | 2列が互いを並べ替え列にしている | 片方の設定を解除する |
| 階層に列が追加できない | 別テーブルの列を入れようとした | 階層はテーブル内で完結させる |
| マップが海外を指す | データカテゴリが未設定 | 都道府県などのカテゴリを設定する |
| 列を隠したら階層から消えた | 階層の構成列を非表示にした | 階層で使う列は表示のままにする |
| 整理したのにモデルが軽くならない | 非表示はサイズを減らさない | Power Query で列そのものを削除する |
| 同じ指標のメジャーが複数ある | 定義が集約されていない | 正を1つ決め、他を削除して説明を付ける |
