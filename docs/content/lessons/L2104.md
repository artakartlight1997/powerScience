## Power BI での実装手段

| やりたいこと | Power BI での実装 |
|---|---|
| ページを順に見せる | ページナビゲーションボタン、ブックマークナビゲーター |
| 段階的に要素を出す | ブックマークで表示/非表示を切り替え、ボタンで進める |
| 主張をタイトルに書く | DAXメジャーを作り、タイトルの「fx」から条件付き書式で適用 |
| 注釈を添える | テキストボックス、シェイプ。ブックマークで表示制御も可能 |
| 強調を動的にする | 条件付き書式（データの色）にDAXメジャーを指定 |
| 深掘りを促す | ドリルスルー、ツールチップページ |

```dax
分析タイトル =
VAR 当年 = [売上合計]
VAR 前年 = [売上合計_前年同期]
VAR 差率 = DIVIDE( 当年 - 前年, 前年 )
VAR 連続月数 = [前年割れ連続月数]
RETURN
SWITCH(
    TRUE(),
    ISBLANK( 前年 ), "比較対象期間のデータがありません",
    連続月数 >= 3,
        "売上は" & 連続月数 & "か月連続で前年割れ（直近 " & FORMAT( 差率, "+0.0%;-0.0%" ) & "）",
    差率 < 0, "売上は前年比 " & FORMAT( 差率, "-0.0%" ) & "。単月の落ち込み",
    "売上は前年比 " & FORMAT( 差率, "+0.0%" ) & "で推移"
)
```

> [!EXAM] PL-300で問われる
> **ブックマークとボタンによるナビゲーション**、**選択ウィンドウによる表示制御**、**条件付き書式によるタイトルの動的変更**、**プレゼンテーションモード**、**PowerPoint への埋め込み**。「同じページでビジュアルを切り替えたい」→ブックマーク＋ボタンが定番。

ストーリーテリングの本質は、**聞き手の認知の負担を語り手が引き受けること**です。10時間で理解した構造を、5分で理解できる形に圧縮します。

## 理解度チェック

1. 「今月の売上レポートです。以上」を、4要素で組み直せ（架空の数字で可）。
2. 「地域別売上」をアクションタイトルに書き換えるには何が必要か。手順は。
3. 結論が依頼者の期待と逆だった。誠実さを保ちつつ建設的に伝える方法は。
