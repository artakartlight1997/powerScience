## まん中の白い場所

いちばん広い場所。ここにグラフが並んでいく。

```figure
{ "type": "matrix", "title": "画面のどこに何があるか",
  "xLabel": "左右", "yLabel": "上下",
  "xLow": "左", "xHigh": "右", "yLow": "下", "yHigh": "上",
  "quadrants": [
    {"title": "上のならび", "text": "「ホーム」などの文字が横に並ぶ。データを読み込むのはここ。", "tone": "blue"},
    {"title": "右がわ 2列", "text": "上：グラフの種類を選ぶ。下：読み込んだ列の名前がならぶ。", "tone": "amber"},
    {"title": "左はし", "text": "3つの小さな絵。表示の切りかえ。", "tone": "violet"},
    {"title": "まん中", "text": "白い作業場所。ここにグラフが置かれる。", "tone": "green"}
  ],
  "caption": "作業はほとんど「右で選んで、まん中に置く」のくり返し" }
```

白い場所は、**画用紙**だと思えばいい。

グラフというシールを、好きな場所に貼っていく。貼る場所も大きさも、あとから変えられる。

## 右がわの2つの列

ここがこの道具の心臓部だ。上下2段に分かれている。

```figure
{ "type": "compare", "title": "右がわの上と下",
  "caption": "上で「形」を決め、下で「中身」を決める",
  "panels": [
    {"title": "上：グラフの種類を選ぶ", "tone": "amber", "items": [
      "小さな絵がたくさん並んでいる",
      "棒グラフ、折れ線、円、表など",
      "押すと、まん中に空っぽの枠ができる"],
     "note": "先に形を決める"},
    {"title": "下：どの列を使うか決める", "tone": "green", "items": [
      "読み込んだ表の列の名前がならぶ",
      "「日付」「味」「個数」「金額」など",
      "チェックを入れると、枠に中身が入る"],
     "note": "あとから中身を入れる"}
  ] }
```

> [!TIP] 名前が違って見えても大丈夫
> この下の列は、道具の新しさで名前が変わる。
> 「データ」と書いてあることも、「フィールド」と書いてあることもある。
> 中身は同じ。読み込んだ表の列がならぶ場所だ。

## 作る手順は、いつもこの2歩

```figure
{ "type": "steps", "title": "グラフができるまで",
  "caption": "この2歩だけ。どんなグラフでも同じ",
  "items": [
    {"title": "形を選ぶ", "text": "右上の絵から棒グラフを押す。まん中に空っぽの枠が出る。"},
    {"title": "中身を入れる", "text": "右下の「味」と「個数」にチェックを入れる。枠に棒が現れる。"}
  ] }
```

順番を逆にしてもいい。列にチェックを入れてから形を変えても、同じところに着く。

## 左はしの3つの絵

たてに小さな絵が3つ並んでいる。**表示の切りかえ**だ。

```figure
{ "type": "cards", "cols": 3, "title": "3つの表示",
  "caption": "ふだんは1つ目にいる。2つ目は確かめたいときだけ",
  "items": [
    {"icon": "📊", "title": "グラフを置く場所",
     "text": "ふだんはここ。この本のほとんどの作業はこの表示で行う。",
     "tone": "green"},
    {"icon": "🔢", "title": "表そのものを見る場所",
     "text": "読み込んだデータが表のまま並ぶ。中身を目で確かめるときに使う。",
     "tone": "blue"},
    {"icon": "🔗", "title": "表と表のつなぎ目を見る場所",
     "text": "表が2枚以上になったときに使う。第4章まで出番はない。",
     "tone": "gray"}
  ] }
```

いま覚えるのは1つ目と2つ目だけでいい。3つ目は第4章で戻ってくる。
