## スマホのホーム画面と、同じ考え

```figure
{ "type": "compare", "title": "スマホのホーム画面 / この1枚",
  "caption": "どちらも、よく見るものを目の行く場所に置くという同じ話",
  "panels": [
    {"title": "スマホ", "tone": "amber", "items": [
      "毎日使うアプリは1ページ目",
      "たまに使うものは2ページ目",
      "使わないものは消す"]},
    {"title": "この1枚", "tone": "blue", "items": [
      "毎日見る数字は左上",
      "たまに見るグラフは下",
      "使わないグラフは消す"]}
  ] }
```

ちがうところが1つある。スマホは自分の使いやすさで決めるが、この1枚は見る人に合わせて決める。
