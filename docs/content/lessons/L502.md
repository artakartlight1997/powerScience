「じいちゃん、パソコンで見てよ」と言ったら、断られた。

「あれは家にしかないじゃろ。店では、これしか持っとらん」

## 店にあるのは、スマホだけ

おじいちゃんが出したのは、ひび割れた古いスマホだった。

朝の仕こみを決めるのは、家ではなく店の鉄板の前。そこにパソコンはない。

```figure
{ "type": "cards", "cols": 3, "title": "だれが、どこで、何で見るか",
  "caption": "作った場所と、見る場所はちがう。見る場所に合わせて作る",
  "items": [
    {"icon": "👴", "title": "おじいちゃん", "text": "店の鉄板の前。朝5時。スマホをかた手に、立ったまま見る。", "tone": "amber"},
    {"icon": "👩", "title": "お母さん", "text": "買い出しのとちゅう。スーパーの前でスマホを見る。", "tone": "violet"},
    {"icon": "👦", "title": "あき", "text": "家のつくえ。パソコンで作る。すわって、じっくり見る。", "tone": "blue"}
  ] }
```

## 店でためす

作りおわったら、自分のスマホで開いて店まで持っていく。

```figure
{ "type": "steps", "title": "店でのたしかめ方",
  "caption": "つくえの上ではなく、使う場所でためす",
  "items": [
    {"title": "立ったまま、かた手で見る", "text": "店ではこの姿勢になる。すわって見てはいけない。", "tone": "blue"},
    {"title": "指で広げたくなったら、負け", "text": "広げないと読めないなら、字が小さい。もっと大きくする。", "tone": "amber"},
    {"title": "おじいちゃんに持たせる", "text": "自分で持つと分かってしまう。本人にさわってもらう。", "tone": "green"}
  ] }
```

おじいちゃんは、ねじりはち巻きのままスマホをのぞいた。そして「これなら見えるわ」と言った。

> [!NOTE] 次にすること
> ならびはできた。でも、このままではあきのパソコンの中にあるだけだ。次は、おじいちゃんに届ける。
