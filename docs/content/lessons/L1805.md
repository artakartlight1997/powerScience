検索窓に「売上」と入れたら47件出てきた。どれが正しいのか利用者には分かりません。

正しい打ち手は削除ではありません。**「これが正です」という表示を1件に付ける**ことです。

## 理解度チェック

1. 「昇格済み」と「認定済み」の違いを、付与する人の観点から説明してください。
2. 影響分析で系列ビューに何も出ませんでした。それでも確認すべきことは何ですか。
3. 似たレポート47件を「46件削除する」進め方が失敗する理由と、最初の一手を述べてください。

## よくあるエラーと対処

| 症状 | 原因 | 対処 |
|---|---|---|
| 認定済みが信用されない | 誰でも付与できる状態 | 付与できる人を管理ポータルで限定 |
| 所有者不明の認定済みが残る | 取り消しの運用がない | 年次で再確認し、満たさなければ取り消す |
| カタログの説明欄が埋まらない | お願いベースで依頼した | 説明の記載を認定の必須条件にする |
| 列削除でExcelブックが全滅 | 系列ビューに出ない依存 | アクティビティログで利用実績を確認 |
| 共有モデルを作ったが使われない | 定義の合意より先に実装した | 合意 → 実装 → 付け替え → 廃止の順に戻す |
