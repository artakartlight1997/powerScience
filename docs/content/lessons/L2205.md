## ① 時間削減 — まず確実な効果から

```figure
{ "type":"formula", "lang":"text", "title":"時間削減効果の算定", "caption":"「BIのおかげ」と言うには導入前の実測が要る",
  "code":"年間効果額 = ( 削減時間/回 × 回数/年 × 対象人数 ) × 時間単価",
  "parts":[
    {"match":"削減時間/回","label":"導入前後の実測差。自己申告ではなく計測する","tone":"blue"},
    {"match":"回数/年","label":"週次なら52、月次なら12","tone":"green"},
    {"match":"対象人数","label":"実際にその作業をしていた人数","tone":"amber"},
    {"match":"時間単価","label":"人件費÷年間労働時間。経理から公式値を取る","tone":"violet"} ] }
```

```text
【算定例】営業所長向け週次レポート
  導入前: 部下からのExcel報告を集計 → 週2.0時間
  導入後: レポートを開いて確認     → 週0.2時間
  年間効果 = 1.8時間 × 52週 × 40名 × 4,500円/時 = 16,848,000円

過大主張を避けるための注記
  ・40名中の完全移行は34名（利用率85%）→ 実効値 14,320,800円
  ・開発・運用コスト 380万円を差し引いた純効果は約 1,050万円
  ・浮いた時間の行き先まで書く：集計の週1.8時間が顧客訪問に回り、訪問件数が月3.2件増
```

T3までで身につけたのは「正しい数字を、速く、安全に作る力」でした。

T4で加わったのは「**その数字で、何を変えるかを決める力**」です。

技術は数年で変わります。しかし、誰の何の意思決定を助けるのかを問い、事業を数式に分解し、データの信頼性を担保し、人に伝えて動かす技能は、ツールが変わっても価値を失いません。
