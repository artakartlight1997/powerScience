「BIチームは何の役に立っているのか」——この問いに、金額で答えられなければ予算は削られます。そして同じ問いは、あなた個人にも向けられます。「あなたを採用すると、うちの会社に何が起きますか」

効果測定は、組織のためだけの作業ではありません。**自分の仕事の価値を、自分の言葉で語れるようにする作業**です。

## ① 時間削減 — まず確実な効果から

最も算定しやすく、反論されにくい効果です。ただし**「BIを導入したから」と主張するには、導入前の実測が必要**です。

```figure
{ "type":"formula", "lang":"text", "title":"時間削減効果の算定",
  "code":"年間効果額 = ( 削減時間/回 × 回数/年 × 対象人数 ) × 時間単価",
  "parts":[
    {"match":"削減時間/回","label":"導入前後の実測差。自己申告ではなく計測する","tone":"blue"},
    {"match":"回数/年","label":"週次なら52、月次なら12","tone":"green"},
    {"match":"対象人数","label":"実際にその作業をしていた人数","tone":"amber"},
    {"match":"時間単価","label":"人件費÷年間労働時間。経理から公式値を取る","tone":"violet"} ] }
```

```text
【算定例】営業所長向け週次レポート

導入前: 各所長が部下からのExcel報告を集計 → 週2.0時間
導入後: レポートを開いて確認 → 週0.2時間
削減:   週1.8時間

年間効果 = 1.8時間 × 52週 × 40名 × 4,500円/時 = 16,848,000円

補足（過大主張を避けるための注記）:
- 浮いた時間が他の生産的業務に使われている前提での試算
- 40名のうち完全移行済みは34名（利用率85%）→ 実効値 14,320,800円
- 開発・運用コスト 380万円を差し引いた純効果は約1,050万円
```

> [!TRAP] つまずきポイント
> **時間削減効果をそのまま「利益」と言うと、経理や役員から必ず突っ込まれます。** 「人が減ったわけではないので、コストは減っていない」というのが正論です。だから**「浮いた時間で何をしたか」まで書いてください。**「集計に使っていた週1.8時間が、顧客訪問に振り向けられ、訪問件数が月平均3.2件増えた」——ここまで書けば反論されません。

```figure
  "items":[
    {"icon":"⚡","title":"リードタイム短縮","text":"問題の発生から気づくまでの日数。月末発覚 → 翌日発覚 なら29日短縮","tone":"blue"},
    {"icon":"📊","title":"データに基づく決定の割合","text":"会議で数字を根拠に決めた件数の比率。議事録から数えられる","tone":"green"},
    {"icon":"🎯","title":"判断の精度","text":"予測と実績の乖離。需要予測の誤差率など","tone":"amber"},
    {"icon":"🏃","title":"実行率","text":"決めたことが実行された割合。可視化されると実行率は上がる","tone":"violet"} ] }
```

リードタイム短縮は金額に翻訳できます。「異常の発覚が29日早まった」なら、**その29日間に発生していたはずの損失**が防げた額です。

```text
【算定例】欠品の早期検知

導入前: 欠品に気づくのは月次締めの翌月5日（平均発生から20日後）
導入後: 日次アラートで翌日に検知（1日後）
短縮:   19日

1店舗あたりの欠品による機会損失 = 1日 12,000円
年間の欠品発生回数 = 全店で 240回
効果 = 19日 × 12,000円 × 240回 × 検知後の是正率 60% = 32,832,000円

前提の明示:
- 是正率60%はパイロット期間の実測値
- 検知しても即日補充できないケースを考慮済み
```

## ③ 収益・コストへの影響

最もインパクトが大きく、最も証明が難しい領域です。ここで必要になるのが**ベースラインと比較設計**です。

```figure
{ "type":"compare", "title":"効果測定の設計", "caption":"「導入後に売上が伸びた」だけでは何の証明にもならない",
  "panels":[
    {"title":"証明にならない主張","tone":"bad",
     "items":["「導入後、売上が8%伸びました」","「利用部署の成績が良いです」","「現場から好評です」","「多くの人が使っています」"],
     "note":"季節性・他施策・選択バイアスを排除できていない"},
    {"title":"証明になる主張","tone":"good",
     "items":["「導入した20店と、未導入の20店を比較して +5.2pt の差」","「導入前12か月と後12か月で、同一店舗の伸び率を比較」","「対象をランダムに分け、3か月後の差を検定」","「効果の大部分が説明できない要因は明示する」"],
     "note":"比較の設計がある"} ] }
```

> [!DS] データサイエンス視点：反実仮想という考え方
> 因果推論の中心にあるのは**反実仮想**（counterfactual）——「もしBIを導入していなかったら、売上はどうなっていたか」という、観測できない世界の値です。これは絶対に観測できないので、**近似する**しかありません。近似の手段が、(1)**ランダム化比較試験**（最も強い。対象をランダムに分ける）、(2)**差分の差分法**（導入群と非導入群の、導入前後の変化の差を取る）、(3)**回帰不連続**や**合成対照法**（似た性質の非導入群を人工的に構成する）です。厳密さの順序を知っておき、**自分の主張がどのレベルの証拠に基づくかを正直に述べる**ことが、長期的な信頼を作ります。

```figure
{ "type":"chart", "kind":"line", "title":"差分の差分法による効果推定", "caption":"導入群と対照群の差の拡大分（3.9pt）が推定効果",
  "categories":["導入6か月前","4か月前","2か月前","導入","2か月後","4か月後","6か月後"],
  "series":[
    {"name":"導入群","values":[100,101,102,103,106,109,112],"tone":"blue"},
    {"name":"対照群","values":[100,101,102,103,104,105,106],"tone":"gray"} ],
  "highlight":6, "unit":"指数（導入6か月前=100）" }
```

この図の要点は、**導入前の2本の線が平行に動いていること**です（平行トレンド）。導入前から差が開いていたら、この手法は使えません。効果測定を設計する際は、**導入前のデータを最低6か月分は確保**してください。

```figure
    {"match":"年間効果額","label":"時間削減＋意思決定改善＋収益影響。控えめに見積もる","tone":"good"},
```

| コスト項目 | 見落とされがちな内訳 |
|---|---|
| 初期開発 | 要件定義、データ整備（往々にして開発の2倍かかる）、テスト、研修 |

> 右上に行く最短経路は、**事業側の会議に出席させてもらうこと**です。営業会議、商品会議、経営会議。数字を出す係として参加を申し出れば、たいてい歓迎されます。そこで交わされる議論こそが、事業理解の教材です。レポートを作る部屋にこもっていては、右上には行けません。

技術は数年で変わります。Power BI が別のツールに置き換わる日も来ます。しかし、**誰の何の意思決定を助けるのかを問い、事業を数式に分解し、データの信頼性を担保し、人に伝えて動かす**——この一連の技能は、ツールが変わっても価値を失いません。
