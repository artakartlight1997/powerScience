ここからは実際に手を動かします。所要40分、最後には自分の手でグラフが1枚できあがります。

## 準備するもの

| 必要なもの | 補足 |
|---|---|
| Windows PC | Power BI Desktop は Windows 専用です |
| Power BI Desktop | Microsoft Store 版が自動更新されるためおすすめ |
| サンプルデータ | 本サイトの [sales.csv](data/sales.csv) をダウンロード |

> [!NOTE]
> Mac をお使いの場合、Power BI Desktop は動きません。選択肢は3つあります。(1) Windows仮想マシン／Parallels、(2) クラウドPC（Windows 365 など）、(3) ブラウザ版 Power BI Service で簡易的に作成する。学習用途なら (3) でも Lv.1〜Lv.3 の大半は追随できますが、ハンズオンは (1)(2) を推奨します。

## インストール

1. Microsoft Store を開き「Power BI Desktop」を検索してインストール
2. 起動して、サインイン画面が出たら**組織のアカウントがなければスキップ**でも構いません（作成だけなら不要）
3. 初回起動時のスプラッシュ画面は閉じてしまって大丈夫です

## 画面の地図を先に覚える

最初に画面構成を掴んでおくと、以降の説明で迷いません。

```mermaid Power BI Desktop の3ビュー
flowchart LR
  R["レポートビュー<br/>グラフを配置する"] <--> T["テーブルビュー<br/>データを表で確認する"]
  T <--> M["モデルビュー<br/>テーブル同士をつなぐ"]
  R <--> M
  style R fill:#f6e7f0,stroke:#d3457a
  style T fill:#e7efff,stroke:#2f6fed
  style M fill:#fdf0dc,stroke:#c77700
```

左端の縦に並んだ3つのアイコンがこの3ビューです。**別のアプリではなく、同じファイルの3つの見え方**だと理解してください。

さらに、レポートビューの右側には3つのペインが並びます。

- **データペイン**：使えるテーブルと列の一覧
- **視覚化ペイン**：グラフの種類と、そこに列を放り込む「フィールドウェル」
- **フィルターペイン**：ビジュアル・ページ・レポート単位の絞り込み

## 手順1：データを読み込む

1. リボンの **ホーム → データを取得 → テキスト/CSV**
2. ダウンロードした `sales.csv` を選択
3. プレビューが表示される。ここで**「読み込み」ではなく「データの変換」を押す**

> [!TIP]
> 「読み込み」ではなく「データの変換」を押す癖をつけてください。Power Query エディタが開き、データ型の確認ができます。あとから直すより最初に見るほうが速いです。

4. Power Query エディタで、各列のデータ型アイコンを確認
   - `OrderDate` は日付、`Quantity` は整数、`UnitPrice` は10進数
5. **ホーム → 閉じて適用**

## 手順2：最初のグラフを作る

1. レポートビューで、視覚化ペインから **集合縦棒グラフ** をクリック
2. データペインの `Category` を **X軸** に、`SalesAmount` を **Y軸** にドラッグ
3. グラフの右上「…」→ **軸の並べ替え → SalesAmount → 降順**

これで「カテゴリ別売上」の棒グラフができました。

## 手順3：KPIカードと折れ線を足す

1. 何もない場所をクリックしてから、視覚化ペインの **カード** を選択
2. `SalesAmount` をフィールドに入れる → 合計売上が大きく表示される
3. もう一度何もない場所をクリック → **折れ線グラフ**
4. X軸に `OrderDate`、Y軸に `SalesAmount`

> [!TRAP]
> 新しいビジュアルを作るときは、**必ず何もない余白をクリックしてから**種類を選んでください。既存のビジュアルを選択したまま操作すると、そのビジュアルの種類が変わってしまいます。初学者が最初に必ず一度は踏む罠です。

## 手順4：相互作用を体験する

棒グラフの「家電」の棒をクリックしてみてください。カードの数字と折れ線グラフが、家電だけの数字に変わったはずです。

```mermaid クロスフィルターの動き
flowchart LR
  C["棒グラフで<br/>「家電」をクリック"] --> F["ページ全体に<br/>フィルターが伝播"]
  F --> K["カード：家電の売上"]
  F --> L["折れ線：家電の推移"]
```

これが Power BI の中核体験です。**1か所クリックするとページ全体が連動する**。この裏側で何が起きているかを説明できるようになるのが Lv.3（フィルターコンテキスト）のゴールです。

## 手順5：保存と発行

1. **ファイル → 名前を付けて保存** → `MyFirstReport.pbix`
2. 組織アカウントがある場合は **ホーム → 発行** → ワークスペースを選択
3. ブラウザで Power BI Service が開き、同じレポートが表示される

> [!EXAM]
> `.pbix` にはデータ・モデル・レポートがすべて含まれます。一方 `.pbit`（テンプレート）は**データを含まず、構造とクエリだけ**を保存する形式です。この違いは出題されます。

## つまずいたときは

| 症状 | 原因と対処 |
|---|---|
| 日本語が文字化けする | CSVの読み込み時、右上の「ファイル発生源」を `65001: Unicode (UTF-8)` に変更 |
| 日付が数値になっている | Power Query で列を選び「データ型 → 日付」。ロケールが必要なら「ロケールを使用」から日本語を指定 |
| グラフが空になる | フィールドウェルに列が入っているか、フィルターで全部除外されていないかを確認 |
| 数値が全部1になる | 集計が「カウント」になっている。フィールドの下矢印から「合計」に変更 |
