## 理解度チェック

**問1.** `顧客数 = DISTINCTCOUNT( Fact_売上[CustomerID] )` の総計が明細の和と一致しません。バグですか。

<details>
<summary>解答</summary>

バグではありません。同じ顧客が複数の地域や月で購入すれば、各行で1人ずつ数えられ総計では1人になります。

非加法的指標の正常な挙動です。誤解されないようレポートに注記を入れます。
</details>

**問2.** `CALCULATE( [売上合計], FILTER( Fact_売上, RELATED( Dim_商品[Category] ) = "家電" ) )` が遅い理由は。

<details>
<summary>解答</summary>

FILTER が数百万行を数式エンジンで走査し、行ごとに RELATED を引くためです。`Dim_商品[Category] = "家電"` と書けば一意値だけの走査で済みます。
</details>

**問3.** 秒単位の日時列がモデルサイズを圧迫する理由と対処は。

<details>
<summary>解答</summary>

辞書符号化は一意な値の数だけエントリを作るためです。3年分の秒単位は約860万通りになります。

日付と時刻に分ければ 1,095 + 1,440 = 2,535 通りに減り、圧縮が劇的に効きます。
</details>
