# AI によるアルファ減衰と同質化

> **投資の世界には、他産業にない特殊性がある。**
> **「全員が同じ賢いモデルを使うと、そのモデルから得られる優位はゼロになる」。**
> これは IP の存在意義を、他のどの議論よりも強く規定する。

## 1. 研究

*AI-Driven Alpha Decay: Algorithmic Homogenization, Reflexive Signal Erosion, and the Paradox of Intelligent Markets*
（arXiv:2605.23905, 2026）`[S-117]`

AI 投資戦略は**規模において本質的に自己敗北的**であり、
採用率の上昇が3つの相互強化的な経路で超過リターンを圧縮する `[S-117]`:

1. **シグナルの混雑（signal crowding）**
2. **遂行的なシグナル侵食（performative signal erosion）** — 使うことで消える
3. **レッドクイーン競争** — 走り続けないと同じ場所にいられない

### 定量的な主張 `[S-117]`

| 指標 | 値 |
|---|---|
| 現在の採用水準（約0.7）でのシグナル半減期 | **18ヶ月**（AI 以前は 5〜7年） |
| 機関投資家ポートフォリオの収束（13F、9,950万件、2013-2024で較正） | **サンプル期間で +42%** |
| モノカルチャー均衡での純アルファ | **ゼロ**（AI に多額を投じていても） |

同質化の原因は明快 `[S-117]`:
> **同じライセンスデータ、同じ基盤モデルの重み、同じマクロシグナル** —
> 入力が標準化されている限り、シグナルとポジションの収束は続く。

## 2. IP にとっての含意（これが最重要）

### (a) 「賢いモデルを使う」ことは、投資では優位にならない
むしろ**採用が進むほど優位が消える**。これは他産業にない性質である。
→ **「最新モデルを使っています」は投資顧客に対する訴求にならない**（むしろ「全員と同じ」の証明）。

### (b) 差別化の源泉は、入力の差か、処理の差しかない

| 源泉 | 内容 | IP での実装 |
|---|---|---|
| **入力の差** | 他社が持たないデータ | ファンド固有の VDR / IC メモ / 面談記録、独自の一次情報取得（→ [t-data-sources](data-sources.md)） |
| **処理の差** | 同じ入力から違う結論を出す枠組み | **反証の型・仮説空間の作り方・較正**（＝ IP の目的関数） |
| （参考）**速度の差** | 先に気づく | AI 普及で消えつつある（半減期18ヶ月） |

### (c) 「同じ答えに速く着く」ことの価値は下がり、「違う問いを立てる」ことの価値が上がる
LLM が生成する対立仮説は**訓練分布＝主流コンセンサスに偏る** `[S-061]`。
全員が同じモデルを使えば、**全員が同じ仮説を検討し、同じものを見落とす**。
→ **仮説の多様性を人間と過去案件から供給する**という IP の設計（P3）は、
**アルファ減衰への直接的な対抗策**でもある。

### (d) PE は公開市場より減衰が遅い（が、無縁ではない）
- 13F の収束は公開株の話であり、PE の非公開案件は**そもそも情報が非対称**
- しかし **ソーシングと初期スクリーニングは急速に同質化する**（誰もが同じ DR で同じ市場地図を作る）
- したがって IP が入るべきは、**同質化しやすい工程（スクリーニング）ではなく、
  非対称性が残る工程（一次情報・独自の反証・自社の判断履歴）**
  → [t-pe-dd-workflow](pe-dd-workflow.md) の工程別評価と整合する

## 3. 一行でまとめる

> **モデルが賢くなるほど、モデル由来の優位は速く消える。**
> **残るのは「誰も持っていない情報」と「誰もやっていない問いの立て方」だけ。**
> IP はその2つを構造化する装置である。
