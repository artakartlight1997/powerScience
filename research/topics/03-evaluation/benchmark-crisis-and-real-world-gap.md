# ベンチマークの崩壊と実世界ギャップ

**「モデルが賢くなる」という言明そのものが、2026年時点では測定困難になっている。**
これは IP にとって脅威ではなく、**機会**である（自前の評価が資産になる）。

## 1. 評価の危機

| 問題 | 内容 |
|---|---|
| **飽和** | 2026年2月時点でフロンティアは MMLU 約93%、GSM8K 約99%、HellaSwag 95%超。**1ポイント差は実力差より実行ごとのノイズ**である可能性が高い `[S-116]` |
| **汚染** | Open LLM Leaderboard では MMLU で「汚染確率94%」の例、34B で 85.6 という不可能なスコア。**OpenAI の監査では、テストした全フロンティアモデルが SWE-bench Verified の一部で gold patch や問題文を逐語再現できた** `[S-116]` |
| **過学習** | リーダーボード順位に紐づく体系的な過適合 `[S-116]` |
| **予測力の欠如** | 公開スコアが本番性能を予測するのは「類似タスク・汚染なし・未飽和」の3条件が揃うときのみ `[S-116]` |
| 対策 | **LiveBench**（ICLR 2025 Spotlight）— 毎月、**モデルのカットオフ後の情報**から問題を生成し、汚染を原理的に不可能にする `[S-116]` |

## 2. METR の時間地平（time horizon）

**「モデルはどれくらい長い仕事を任せられるか」を測る、現在最も重要な指標** `[S-110]`。

| 事実 | 数値 |
|---|---|
| 時間地平の倍化周期（2019-2025 全体） | **約7ヶ月** |
| 2024-2025 の倍化周期 | **約4ヶ月** |
| METR の 2026年2月データへのフィット | **105日** |
| 首位（2026-02-21 時点） | **Claude Opus 4.6、50%-時間地平 14時間30分** |
| ベンチ自体の限界 | 228タスク中 **16時間以上は5タスクのみ**。METR 自身が「次のモデルは測れない」と表明 `[S-110]` |

> ### ⚠️ 決定的な但し書き — **「50%」である**
> 時間地平は **「成功率50%でこなせるタスク長」**として定義されている `[S-110]`。
> **14時間半の仕事を、2回に1回失敗する**ということ。
>
> **投資 DD で 50% は使えない。** IC に出す資料に「2回に1回間違い」は許容されない。
> 業務要求水準（95%〜99%）に対応する時間地平は、**これよりはるかに短い**。
> → **能力の伸び（指数関数的）と、業務が要求する信頼性の間には、依然として大きな溝がある。**
> → その溝を埋めるのは**モデルではなく、検証・停止・人間の承認の設計**である。

## 3. GDPval — 実世界の仕事での評価

- OpenAI が公開した、**実際に経済的価値のあるタスク**での評価 `[S-112]`
- **44職種、9産業、1,320タスク**。平均14年の実務経験者と協働して作成 `[S-112]`
- フロンティアモデルは GDPval タスクを **専門家の約100倍速く、約100倍安く**こなせる `[S-112]`

> ### 🔑 含意（両面）
> - **脅威**: 「作る」コストはほぼゼロに向かう。**成果物の生成では絶対に戦えない。**
> - **機会**: 100倍安く大量に作れるからこそ、**「どれが正しいか」「どれに賭けるか」の価値が相対的に上がる**。
>   供給が無限になった財の価値は落ち、**選別と保証の価値が上がる**。

## 4. 実運用ギャップ

- エンタープライズのエージェント AI で、**ベンチと本番の間に 37% のギャップ**、
  同等精度で **50倍のコスト差** `[S-111]`
- **本番の試行の3回に1回が失敗**しているという報告 `[S-111]`

## 5. IP への帰結

1. **公開ベンチでの優位は、主張しても信じられない時代に入った**（飽和・汚染・予測力なし）。
   → 対外的な説得力は **自前の、汚染されない、実案件由来の評価**からしか出ない。
   → [t-ip-evaluation-design](integral-prism-evaluation-design.md) の**反実仮想 DD**は、
     LiveBench 的な発想（カットオフ後・更新可能）と同じ原理で設計する。
2. **50% 時間地平と業務要求（95%+）の差**こそが、我々の商品領域である。
3. GDPval が示す通り**生成は100倍安くなる**。だから IP の課金根拠は生成量ではなく、
   **保証（検証済み・較正済み・監査可能）**でなければならない。
