# 「実益」とは何か

**曖昧なまま進めると、必ず「面白いが使わない」製品になる。** 先に定義する。

## 1. 投資プロにとっての実益（4種類しかない）

| 種類 | 内容 | 金額換算 | 我々が効くか |
|---|---|---|---|
| **V1 時間** | 同じ成果物が早く出る | アナリスト1人日 **¥50,000〜150,000** `推定` | ○（ただし**既にコモディティ**。70–85%削減の報告は既にある `[S-076]`） |
| **V2 損失回避** | **買ってはいけないものを買わない**／価格を下げられる | **1案件で数億〜数十億** | ◎ **桁が違う。ここが本命** |
| **V3 機会獲得** | 見送るべきでない案件を取れる／早く動ける | ディール1本の利益 | △（ソーシングは同質化する `[S-117]`） |
| **V4 説明責任** | IC・LP・監査に対して**説明でき、記録が残る** | 事故時の損失と信用 | ◎（規制も要求 `[S-118][S-079]`） |

> ### 🔑 討論の出発点
> **V1（時間短縮）で戦ってはいけない。**
> 理由: ①既に各社が提供済み ②値付けが「アナリストの時給×削減時間」に固定される
> ③モデルが賢くなるほど競合も同じ削減を実現する（∂V/∂M < 0）
>
> **V2（損失回避）が桁で大きい。** そして V2 は「**見落としを減らす**」という形でしか実現しない。
> **これが「反証エンジン」という製品思想の、経済的な根拠である。**

### V2 の規模感（`推定`、要検証）
```
中規模 PE の1案件: エクイティ投資額 50億〜300億円
「買ってはいけなかった」を回避できた場合の価値: 投資額の全部〜一部
100件に1件でも防げれば、期待値は年間数億円規模
→ 1案件あたり ¥100,000〜¥1,000,000 の支払いは、期待値では明らかに正当化される
→ ただし「防げた」ことは証明しにくい（V2 の売り方の最大の課題 → 03 で扱う）
```

## 2. 経営陣（ファンドのパートナー/CIO）にとっての実益

投資プロ個人の便益と、**組織としての便益は別物**である。ここを混同すると導入が進まない。

| 経営陣が本当に気にすること | 我々の答え |
|---|---|
| **投資判断の質は上がるのか** | 反実仮想 DD で **見落とし率**を測って示す（評価A） |
| **説明できるのか**（LP・IC・監査） | 証拠グラフ＝そのまま説明資料。人間の署名も記録 `[S-118]` |
| **事故は起きないか** | 出荷ゲート（Fact Check ≥95%）と、**誤引用ゼロの保証** |
| **情報は漏れないか** | 案件隔離・二層LLM・学習非利用 `[S-127][S-005]` |
| **チームは実際に使うのか** | PoC 疲れが実在する（scaling は 10–15% `[S-076]`）→ **1工程の正本化**から |
| **いくらかかって、何が返るのか** | **EVPI で「この調査の上限額」を提示できる** `[S-121]` ← 他社にない説明 |

> **経営陣が呆れる典型**: 「AI が100ページのレポートを書きました」→ **「で、誰が読むの？」**
> **100ページは価値ではなくコストである。** → 07 で詳述

## 3. 我々の実益指標（`../method-and-scope.md` の5軸を金額化）

| 軸 | 測り方 | 目標（仮） |
|---|---|---|
| **時間** | IC 提出までのリードタイム | −30%（**主目的にしない**） |
| **見落とし率** | 反実仮想 DD で、後に材料化した事実の事前検出率 | **既存プロセス比 +20pt** |
| **反証可能性** | 主張1件を第三者が検証するのに要する時間 | **5分 → 30秒**（出典スナップショット＋座標） |
| **較正** | Brier / ECE | 素朴な基準率予測を上回る |
| **再利用性** | 過去案件の知見が新案件で参照された回数 | 案件あたり 3件以上 |

## 4. 「実益がない設計」の見分け方 🔒

以下に当てはまる機能は、**作らない**。

1. **成果物が長くなるだけ**の機能（100ページ→200ページ）
2. **人間が結局読み直す**もの（検証コストが減らない）
3. **既存ツールで同じことができる**もの（Hebbia の抽出、Rogo のコンプス）
4. **測れない**もの（「洞察が深まる」）
5. **モデルが賢くなれば要らなくなる**もの（P16）

【決着】**実益は V2（損失回避）と V4（説明責任）に置く。V1（時間）は副産物として言及するに留める。**
【反証条件】顧客ヒアリングで「時間短縮以外に金は出せない」が過半なら、この前提は覆る（→ 03、Q12）
