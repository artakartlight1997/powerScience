# 一次商品の形（D1）

**3案を「月曜の朝、誰の何が変わるか」で比較する。** 抽象論では決まらない。

---

## 案A: バッチ型 DD レポート（Marlin 同型）

**月曜の朝**: アソシエイトが案件名を入れて実行 → 夕方、80ページのレポートが出る。

| | |
|---|---|
| **良い点** | 説明が要らない。「Deep Research の高級版」で通じる。デモが作りやすい |
| **悪い点** | **Marlin と同じ土俵**（¥9,800/回と比較される）。100ページは**読まれない**。生成は100倍安くなる `[S-112]` |
| **実益** | V1（時間）のみ。V2 には届かない |
| **経営陣の反応** | 「で、誰が読むの？」 |

**【判定】単体では採らない。**

---

## 案B: 反証エンジン（仮説×証拠 ＋ 未解決の論点）

**月曜の朝**:
```
VP が IC メモのドラフトを投入 → 30分後に返ってくるもの:
  ① IC で刺されそうな論点 7件（重要度順）
  ② うち 4件は「メモの中に根拠がない」
  ③ うち 2件は「根拠はあるが、原文と食い違う」← ★矛盾検出
  ④ 残り 1件は「調べれば決着する。想定コスト ¥120,000、EVPI は ¥800,000」
  ⑤ 全主張に、原文の該当箇所へのリンク（ページ・座標つき）
```

| | |
|---|---|
| **良い点** | **IC 前の実益が具体的**。裏取り（P4）と想定問答（P5）を同時に解く。**5分で価値が伝わる** |
| **悪い点** | 新カテゴリ＝説明コスト。「反証」という言葉が心理的に重い（F1） |
| **実益** | **V2（損失回避）＋ V4（説明責任）**。IC を通すための道具として売れる |
| **経営陣の反応** | 「IC で刺される論点を事前に出せるのか」＝**分かる** |

**【判定】これを核にする。ただし呼び方を変える。** 🔧
→ 対外的な呼称は「**反証エンジン**」ではなく「**IC レディネス**」「**想定問答と未解決論点**」

---

## 案C: 常駐モニタ（thesis tracking）

**月曜の朝**: 投資済み案件について「先週、投資仮説を揺るがす事象が2件」という通知。

| | |
|---|---|
| **良い点** | 継続課金。データが貯まる。**競合が薄い**。PMI/モニタリングはほぼ手つかず `[S-076]` |
| **悪い点** | **効果が出るまで時間がかかる**（数ヶ月〜年）。初回商談で価値を証明しにくい |
| **実益** | V2（早期発見）。ただし**遅効性** |
| **経営陣の反応** | 「良いが、今の困りごとではない」 |

**【判定】第二波。M4。** ただし**器（証拠グラフと記憶）は最初から作る**ので、追加コストは小さい。

---

## 案D（新）: ハイブリッド — 「IC レディネス」を核に、A を副産物、C を継続層

```
        ┌─────────────────────────────────────────────┐
入力 →  │  証拠グラフ（検証済み・時点つき・追記専用）    │
        └───┬──────────┬──────────┬─────────────────┘
            ▼          ▼          ▼
    ①IC想定問答   ②詳細レポート  ③継続モニタ
    （案B・主力）  （案A・副産物） （案C・第二波）
```

**なぜこれが正しいか**:
- **同じ証拠グラフから3つの view を射影するだけ**（P11）。追加の作り込みが小さい
- 案A を「作らない」のではなく「**副産物として出す**」ことで、
  「レポートも出ます」という**商談上の安心**を与えつつ、価値の中心は案B に置ける
- 案C は器が同じなので、後から**追加コストなしに**始められる

**【決着】案D。核は案B（IC レディネス）、A は副産物、C は第二波。**
**【反証条件】** 顧客が「レポートが本体、想定問答はおまけ」と言うなら、案A 中心に組み替える（→ Q12）

## 補足討論: 「8時間」をどう扱うか

| 立場 | 主張 |
|---|---|
| **A: 時間を売りにすべき** | Marlin が「8時間」で話題を作った。分かりやすい |
| **B: 時間を売りにしてはいけない** | **探索を増やすと引用精度が42%落ちる** `[S-057]`。報酬ハッキングも増える `[S-103]`。**投入量を売るのは、成果を売れない者の言い訳** |

**【決着】立場B。**
我々の売り文句は**「8時間考えます」ではなく「必要なだけ調べ、劣化する前に止めます」**。
そして **「なぜ止めたか」を EVPI で説明できる**（＝これ以上調べても判断は変わらない）。
> **これは競合が真似しにくい。** 「早く止まる」ことを価値として売るには、
> **止める根拠**（EVPI）が要るからである。
