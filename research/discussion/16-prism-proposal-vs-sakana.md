# 提案確定版 — サカナAIに勝る Integral Prism

> **本文書は討論の決着 A2（一次商品）/ A3（楔 W1）を差し替える。**
> ユーザ（投資実務側）の判定: **「ICメモへの事後ツッコミは不要。事前に知りたい」** — W1 は却下。
> 後出しの校閲は ①手戻りが直せないタイミングで来る ②書き手の仕事を否定する形で来る
> ③そもそも知りたいのは書く前 — の三重で誤りだった。
> 修正後の設計は、サーベイの結論（Marlin の弱点 W1–W5、賭けどころ B1–B4）と**より強く整合する**。

## 1. サカナが売っているものの正体

Marlin の商品は突き詰めると「**投入量**」である。8時間考えた、100ページ書いた、数千回呼んだ。
しかしリサーチが示した事実:

- **探索を増やすほど引用の事実精度は落ちる**（ツール呼び出し 2→150 で −42%）`[S-057]`。
  8時間はこの劣化への防御を示していない
- 探索木の**報酬関数は非公開** `C-005`。ビジネスリサーチに機械検証可能な正解はなく、
  自己評価が報酬なら「確信度の高い誤りほど深く掘られる」
- 1実行＝1レポート＝**使い捨て**。案件をまたいで何も貯まらない
- レポートは **DD が終わった頃に届く**。IC にとってレポートは入力であって出力ではない

> **Marlin は「あなたの代わりに調べてくる部下」である。優秀だが、帰ってきた時にはもう質問が変わっている。**

## 2. 提案 — 光を当てる前に分光する

**案件という白色光を、着手の瞬間に仮説のスペクトルへ分光（Prism）し、
DD の全期間を通じて一つの判断へ積分（Integral）する。**

```
Marlin : 質問 ──────────[8時間の闇]──────────▶ 100ページ
Prism  : 案件 ─分光─▶ 作戦盤 ─▶ 証拠が論点を潰していく台帳 ─▶ ICメモは台帳から生成
         (30分)        ↑死因の先出しと差分   ↑矛盾は隠さず提示   ↑全主張に原文座標
```

### Phase 0 — 分光（着手30分）: 作戦盤
ティーザー/IM/初期開示を投入。（任意で）先に人間が死因を3つ書く（P17: AI の出力を見る前に）。
返るのは **1枚の作戦盤**:

- **この案件で判断を分ける論点**（重要度順）— 汎用チェックリストではなく、
  初期資料から検出した**この案件固有の引っかかり**（会計方針の変更、成長率が競合3社と同率 等）
- **各論点の決着方法と値札** —
  「顧客別月次売上を **VDR 請求リストに足せばタダで決着**」
  「これは商業 DD の発注スコープに明記すべき、¥180,000 相当」
- **人間が挙げなかった論点**（差分のみ提示）

**DD 予算 ¥5M–30M の配分そのものに効く。外注の発注書を書く前に出る。**
Marlin には構造的に出せない — 彼らの成果物は調べ終わった後にしか存在しない。

### Phase 1 — 積分（DD 期間中）: 生きた台帳
証拠が入るたび論点へ紐づき、潰れていく。
**矛盾（有報 68% vs マネジメント資料 54%）は平均も隠蔽もせず両方提示**（P20）。
画面の最上部には常に「**次に調べる価値が最も高い1件と、その値札**」。
そして他社が言えない一文: **「これ以上調べても、判断は変わりません」**（残 EVPI < 取得コスト、根拠つき）。

### Phase 2 — IC: メモは台帳から生まれる
書き終えたメモを校閲するのではない。**メモが検証済みの台帳から射影される**ので、
校閲すべき対象が最初から存在しない。全主張に原文のページ・座標（裏取り 5分/件 → 30秒/件）。
署名・監査証跡（FINRA / EU AI Act）は副産物 `[S-118][S-079]`。

### Phase 3 — 保有中: 仮説は死なない
投資後も仮説スペクトルは生き続け、崩れる兆候を監視（thesis tracking）。
外れた予測は**較正データ**として蓄積し、「この形は◯◯案件と同型、あの時の見落としは△△」を
次案件の Phase 0 に供給する。**per-run 課金の Marlin は蓄積を殺す構造。我々は蓄積が本体。**

## 3. サカナに勝る点

| | Marlin | Prism |
|---|---|---|
| 効く時点 | DD の後（納品） | **DD の前と最中**（予算配分・資料請求・止め時） |
| 売るもの | 投入量（8時間・100ページ） | **確信**（探して・見つからず・止めた理由の記録） |
| 探索の報酬 | 非公開（自己評価と推定） | **判断が反転する不確実性の削減**（EVPI、金額で説明可能） |
| 長時間の劣化 | 防御不明（−42% 問題）`[S-057]` | 劣化する前に止める＋独立検証器（別ベンダ・再計算権） |
| 矛盾 | 「調停」する（＝均す） | **保存して突きつける**（P20） |
| 蓄積 | 実行ごとに消える | 型と較正が案件を跨いで育つ（MNPI 対応の3層記憶） |
| 監査・署名 | 不明 | 追記専用の証拠グラフが一次記録（P12） |
| Fugu / Namazu | 彼らの層 | **競合しない。部品として買う** |

**模倣の非対称**: サカナは「8時間考える」を売る限り「早く止まる」を売れない。
自社の売り文句と矛盾するため。これは機能差ではなく**製品思想の非対称**であり、追随は自己否定になる。

Fugu（統率）と Namazu（日本語）とは正面で戦わず調達対象にする。
サカナの垂直4層は「どう答えるか」の層であり、
「**何を先に調べるべきか／いつ止めてよいか／その記録は残るか**」の層は空いたまま。
この層は、モデルが賢くなるほど価値が上がる側にある（較正・検証・私有情報・署名 → [t-model-proof](../topics/06-synthesis/model-proof-differentiation.md)）。

## 4. 一行で

> **サカナ・マーリンは「調べてきます」と言って8時間消える。**
> **インテグラル・プリズムは、消える前に「何を調べるべきで、いくらの価値があり、
> どこで止めてよいか」を先に置き、調べ終わったことを証明して残す。**

## 5. 残る最大の検証点

**着手時の情報の薄さで「当たり前の論点」しか出ないなら、この製品は成立しない。**
最初の実験: 過去の実案件の**初期資料だけ**を与え、後に実際に問題化した事実を
作戦盤が事前に挙げられたかを測る（point-in-time、リーク対策つき → [14-how-we-know-it-works](14-how-we-know-it-works.md)）。
**この実験はそのまま営業デモになる。**
