# リスクと撤退基準

**「いつ止めるか / いつ曲げるか」を先に決めておく。** 走り出してから決めると、必ず走り続けてしまう。

## 1. 技術リスク

| # | リスク | 検知 | 撤退・転換基準 |
|---|---|---|---|
| T1 | **XBRL の自動整合検証が通らない** | M0/E1 | 自動検証率 < 70% なら、**財務 DD の差別化を捨て、商業 DD に絞る** |
| T2 | **日本語文書の OCR が使えない** | M0/E2 | 表抽出 F1 < 0.7 または座標が取れない → **文書取り込みを人手前提の設計に変更**（価値提案が変わる） |
| T3 | **サブ質問分解が定性主張に効かない** | M0/E4 | 定性で κ < 0.4 なら、**L1 接地層は数値・事実主張に限定**し、定性は「反証課題の提示」に留める |
| T4 | **Fact Check が探索量に耐えない** | G10 | 150 回時点で < 85% なら、**探索設計をやり直す**（並列度・検証頻度・粒度） |
| T5 | **確率が実用に足る較正にならない** | G17 | Brier が素朴なベースライン（基準率予測）を下回るなら、**確率提示をやめて「反証の網羅」だけを売る**（仮説A のみ） |
| T6 | **インジェクション耐性が作れない** | G15 | 既知攻撃を止められないなら、**Web 自律巡回を外し、閉じたデータのみを扱う製品にする** |

## 2. 事業リスク

| # | リスク | 検知 | 撤退・転換基準 |
|---|---|---|---|
| B1 | **較正に金を払わない** | 顧客ヒアリング（Q12） | 10件中1件も価値を認めないなら、**仮説B を降ろし、仮説A（反証）＋C（記憶）に集中** |
| B2 | **ベンダーのライセンスが AI 利用を禁じる** | Q26（契約前に確認） | 主要ベンダが NG なら、**公開データ＋顧客固有データのみで成立する設計に組み直す** |
| B3 | **データベンダーが判断層に降りてくる** | Q24 の定期監視 | PitchBook / Capital IQ が反証・較正を出したら、**顧客固有データの深さで戦う**（彼らは VDR を持たない） |
| B4 | **Sakana が日本語金融に降りてくる** | Marlin の機能追加を監視 | EDINET-Bench + Namazu + Marlin が揃っている `[S-016][S-105]`。**実務工程（IC/PMI）と顧客データで戦う。汎用リサーチ品質では戦わない** |
| B5 | **調達（セキュリティ審査）に3–6ヶ月** | 初回商談 | 想定内。**公開データだけで動く体験版**を先に出せる設計にしておく |
| B6 | **PoC 疲れ**（PE の scaling は 10–15% `[S-076]`） | 商談 | 「全社導入」を売らない。**1工程の正本化**から入る |

## 3. 構造リスク（気づきにくい）

| # | リスク | 兆候 | 対処 |
|---|---|---|---|
| S1 | **報酬ハッキング**（内部指標だけ良くなる） | proxy − real の乖離拡大 `[S-103]` | G18 で監視。乖離拡大時は**探索を止める** |
| S2 | **judge の腐敗**（安い judge で回して何も改善していない） | judge 相関の低下 `[S-093]` | G14。相関が割れたら judge 交換 |
| S3 | **記憶の濁り**（貯めるほど検索が悪化） | 記憶ヒット時の品質が下がる `[S-052]` | 選別・時効・案件隔離。**量を誇らない** |
| S4 | **Class A への工数流出**（気づくとオーケストレータを作っている） | `adapters/` が厚くなる | 四半期の棚卸し（P16） |
| S5 | **人間介入が精度を下げる** | 介入ありの方が悪い `[S-114]` | I1'（先に人間）形式を守る。承認型 UI を作らない（P17） |
| S6 | **評価が汚染される** | 反実仮想 DD の成績が不自然に良い | リーク検出（G4）、カットオフ後事案の追加、匿名化 |

## 4. 「止める」と「曲げる」の区別 🔒

```
止める（プロジェクト中止）:
  B1（誰も較正に金を払わない）かつ 仮説A も刺さらない
  = 我々の point of view 自体が市場に無い

曲げる（スコープ変更）:
  T1/T2/T3/T6 = 技術的な制約 → 扱う範囲を狭める
  B2/B3/B4    = 競争環境の変化 → 戦う場所を変える
  ★ 曲げるときも「証拠グラフが中心」は変えない。これが最後まで残る資産
```
