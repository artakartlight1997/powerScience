# コンポーネント一覧と責務

**機能層 L0–L9（`../metadata/taxonomy.json`）を、実装単位に落としたもの。**
役割ごとに**権限とモデルを変える**（P5 / P18 / 異質性の要請）。

## 2. コンポーネント表

| # | コンポーネント | 責務 | 権限 | モデル | 層 |
|---|---|---|---|---|---|
| C1 | **決定フレーム** | 投資判断（Go/No-Go・価格・条件）と、反転しうる前提の構造化 | なし | 高性能 + **人間** | — |
| C2 | **仮説空間ビルダ** | ACH の列を作る。型・ケース記憶・人間入力から（P3） | 読み取りのみ | 高性能 | L3 |
| C3 | **探索プランナ** | Question に EIG/EVPI とコストを付け、予算配分し、並列度を決める | 予算の割当 | 高性能 | L3 |
| C4 | **取得ワーカ群** | Web / DB / 文書 / 人 から Evidence を取る（並列） | **未信頼側。ツール権限なし** `[S-127]` | 安価 | L0/L9 |
| C5 | **接地検証器** | 主張↔原文の照合。**サブ質問へ分解して二値判定** `[S-102]` | **原文取得権** | **別ベンダ** | L1 |
| C6 | **数値エンジン** | 決定論的計算・恒等式・XBRL 検証・三値抽出 | **コード実行権** | コード（LLM は式の指定のみ） | L2 |
| C7 | **時系列整合器** | as_of / valid_from の整合、後知恵の検出、修正再表示の追跡 | DB 権限 | 軽量 | L2 |
| C8 | **矛盾検出器** | Evidence 間の食い違いを `contradicts` 辺にする（**解消しない**）P20 | 読み取り | 中位 | L2 |
| C9 | **反証エンジン（レッドチーム）** | 仮説を殺す証拠を探す課題を生成。世代的に強化 `[S-015][S-094]` | 生成の理由は見ない | 高性能・別プロンプト系 | L3 |
| C10 | **確率層** | 変数と依存を抽出 → **アルゴリズムで推論** → 較正を記録 `[S-124]` | 計算 | 構造抽出のみ LLM | L4 |
| C11 | **停止条件エンジン** | EIG 閾値 / 予算 / 反証枯渇 / 確度収束 / **劣化検知**（P15） | 実行の停止 | ルール | — |
| C12 | **記憶（ケースベース）** | 「効いた事実＋反証結果」の選別保存と、同型ケースの供給 | 案件横断（要ポリシー） | 中位 | L5 |
| C13 | **射影器（view）** | グラフから IC メモ / レポート / スライド / 反証サマリを生成 | 読み取り | 中位 | — |
| C14 | **監査・署名** | 追記専用記録、ハッシュ連鎖、人間署名の記録（FINRA）`[S-118]` | 書き込み（追記のみ） | — | L7 |
| C15 | **ポリシーゲート** | capability チェック、egress 制御、案件隔離（P18） | **全ツール呼び出しを仲介** | ルール | L9 |

## 3. 重要な設計判断 🔒

### (a) 並列にするもの / しないもの（P1）
- **並列**: C4 取得ワーカ、C5 接地検証（証拠単位）、C9 反証課題の個別検証
- **逐次・単一統制**: C3 探索プランナ、C10 確率層、C13 射影
  （MAST: 無統制の分散は誤りを17倍に増幅、中央集権＋検証で4.4倍 `[S-029]`）

### (b) 生成と検証でベンダを分ける（P5）
C4/C9（生成側）と C5/C6（検証側）は**必ず別ベンダのモデル**にする。
同一モデルは同一の盲点を共有する。ただし**案件内のキャッシュ効率とのトレードオフ**があるため、
**生成側は案件内で固定、検証側だけ別ベンダ**とする 🔧（→ [06-tech-choices.md](06-tech-choices.md)）

### (c) C15 は全ツール呼び出しの唯一の通り道
「エージェントが直接ツールを呼ぶ」実装を許さない。
**C15 を通らない経路があれば、P18 は成立しない。**

### (d) C9（反証）は C2（仮説生成）と分ける
同じコンポーネントが仮説を作り反証もすると、**自分の仮説に甘くなる**。
DRQ / RQGM が示すのは「**反証役を独立に、世代的に強くする**」ことの効果 `[S-015][S-094]`。
